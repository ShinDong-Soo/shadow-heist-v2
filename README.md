# Shadow Heist V2

보이지 않는 경비원의 위치를 빛과 소리로 추측하고, 한 번 확인한 길을 기억하며 보물을 훔치는 브라우저 스텔스 게임 프로토타입입니다.

분야별 구현 내역과 시스템 규칙은 [개발 문서 목차](docs/README.md)에서 확인할 수 있습니다.

## 실행

```bash
npm install
npm run dev
```

## 조작

- `WASD` / 방향키: 이동
- `Shift`: 조심히 걷기
- `C`: 누르고 있는 동안 웅크리기
- `E`: 보물·키카드 획득, 문 열기·닫기, 숨기·나오기, CCTV 제어반, 조명 스위치, 출구 탈출
- `F2`: 플레이테스트 진단 패널

## 현재 목표

가치가 다른 보물 세 개 중 하나 이상을 훔친 뒤 시작 지점의 출구로 돌아오면 성공합니다. 추가 보물을 노릴수록 점수와 경계 단계가 함께 증가합니다.

서로 무전으로 정보를 공유하는 경비원들과 회전 CCTV의 시야를 피하고 문, 조명, 은신처를 이용해 탈출해야 합니다. 일반 걷기와 문 조작은 경비의 소리 조사를 유발할 수 있습니다. 가장 비싼 왕관은 보안 키카드가 필요하며, CCTV 경보나 마지막 보물 획득 후에는 출구 봉쇄가 풀릴 때까지 살아남아야 합니다. 체포되면 해당 판에서 얻은 점수를 모두 잃습니다.
