# 3D 왕관 강탈 시퀀스 — Phase 06

이 문서는 왕관을 훔치는 순간부터 출구가 다시 열릴 때까지 어떤 코드가 어떤 순서로 움직이는지 초보 개발자도 따라갈 수 있게 설명한다.

## 플레이 흐름

```text
INFILTRATION
→ 왕관 앞에서 E를 1초간 누름
→ CROWN_STEAL
→ 왕관 획득 연출과 짧은 정적
→ 붉은 경보, 셔터, 경비 ALERT
→ LOCKDOWN 18초
→ 셔터 개방
→ ESCAPE
```

왕관은 더 이상 `E`를 한 번 눌렀을 때 즉시 사라지지 않는다. 누르는 도중 `E`를 놓거나 경비에게 완전히 발각되면 진행도가 취소되고 원래 상태로 돌아간다.

## 담당 코드

| 파일 | 역할 |
|---|---|
| `core/GamePhase.ts` | 게임 단계 이름을 한곳에서 정의한다. |
| `core/GameFlowManager.ts` | 현재 단계, Hold 진행도, 18초 타이머와 시스템 전환을 관리한다. |
| `systems/CrownStealSequence.ts` | 0~1.6초 사이에 실행할 연출 순서를 관리한다. |
| `systems/AlarmSystem.ts` | 붉은 경고등, 조명 변화, 잠입·탈출 배경음과 경보음을 담당한다. |
| `systems/SecurityGate.ts` | 출입구 셔터 이동과 닫힌 상태의 충돌 영역을 담당한다. |
| `entities/treasure/Crown.ts` | 왕관의 접근 조건, 플레이어 방향 이동, 획득 상태만 담당한다. |
| `entities/treasure/CrownDisplay.ts` | 유리 케이스 상승과 왕관 Spotlight 소등을 담당한다. |

왕관이 경보나 셔터를 직접 제어하지 않는다. `GameFlowManager`가 시퀀스의 신호를 받아 각각의 시스템에 명령하기 때문에 다음 단계에서 경비 추격을 추가해도 왕관 코드를 다시 뒤엉키게 만들 필요가 없다.

## 강탈 타임라인

| 시간 | 변화 |
|---:|---|
| 0.00초 | 왕관이 플레이어 쪽으로 이동하기 시작한다. |
| 0.30초 | 왕관이 사라지고 `CROWN_STOLEN` 이벤트가 한 번 발생한다. |
| 0.55초 | 금색 왕관 Spotlight가 꺼진다. |
| 0.75초 | 붉은 경보등, 경보음과 탈출 음악이 시작된다. |
| 0.95초 | 입구 Security Gate가 약 2.4초 동안 내려간다. |
| 1.05초 | 경비가 빠른 ALERT 순찰 경로로 바뀐다. |
| 1.25초 | 목표가 `SURVIVE LOCKDOWN`으로 바뀌고 18초 타이머가 시작된다. |
| 1.60초 | 플레이어 조작 제한과 카메라 근접 연출이 끝난다. |

전체 게임은 멈추지 않는다. 왕관을 확보하는 짧은 순간에만 플레이어 이동을 막고 경비·조명·타이머는 계속 갱신한다.

## 조명과 사운드

- 평상시에는 매우 작은 잠입용 저음이 재생된다.
- 강탈 완료 직후 약 0.75초 동안 잠입음이 사라져 짧은 정적을 만든다.
- 경보가 시작되면 두 개의 실제 Point Light와 발광 경고등이 천천히 점멸한다.
- 경보음은 발소리를 덮지 않도록 짧고 작은 전자음으로 반복된다.
- 셔터는 하강 모터음과 닫힐 때의 짧은 금속 충돌음을 사용한다.
- 오디오는 Web Audio로 생성한다. 브라우저가 오디오를 막거나 초기화에 실패해도 게임 상태는 계속 진행된다.

## Security Gate 충돌

셔터가 천장에 있을 때는 플레이어 충돌 영역이 맵 밖에 있다. 셔터가 68% 이상 내려왔을 때만 출입구 충돌 영역을 활성화한다.

```text
OPEN / OPENING
→ 통과 가능

CLOSING 68% 이상 / CLOSED
→ 출입구 차단
```

18초가 끝나면 셔터가 다시 올라가고 충돌 영역도 제거된다. 경보와 경비 ALERT는 유지되므로 ESCAPE 단계도 안전하지 않다.

## 경비 변화

평상시 경비는 왕관실 외곽을 넓게 순찰한다. 경보 후에는 왕관 전시대, 출구, 좌우 엄폐 경로를 반복해서 확인하는 8지점 경계 경로로 바뀐다.

- 순찰 속도: `1.85m/s`
- ALERT 속도: `2.55m/s`
- ALERT 손전등 좌우 흔들림: 평상시의 `2.5배`

플레이어를 발견하면 기존 `DETECTED` 회전 반응이 ALERT보다 우선한다. 실제 추격과 마지막 목격 위치 수색은 Phase 07 범위다.

## UI와 조작

| 조작 | 기능 |
|---|---|
| `Hold E` | 왕관 강탈 진행 |
| `R` | 왕관실 전체 상태 재시작 |
| `Shift + R` | 카메라만 초기화 |
| `F4` | 왕관 앞 테스트 위치로 이동 |
| `F5` | 엄폐 LOS 테스트 |
| `F6` | Hold 과정을 건너뛰고 강탈 시퀀스 시작 |

숨김 상태인 Lockdown UI에는 현재 단계, 남은 시간과 게이트 상태만 표시한다. 개발 패널에는 `GamePhase`, Sequence 시간, Gate, Alarm, Guard와 Lockdown Timer가 표시된다.

## 재시작 시 복원 항목

`R`을 누르면 다음 상태가 모두 초기화된다.

- Crown `AVAILABLE`
- 유리 케이스 닫힘
- Crown Spotlight 켜짐
- Alarm과 붉은 조명 꺼짐
- Security Gate 열림
- Guard 기본 순찰과 시작 위치 복원
- Detection `CLEAR 0%`
- Player 시작 위치와 입력 잠금 복원
- GamePhase `INFILTRATION`
- Lockdown Timer 18초

## 검증 결과

로컬 인앱 브라우저에서 다음 시나리오를 확인했다.

| 시나리오 | 결과 |
|---|---|
| 짧게 E를 눌렀다가 놓기 | `STEAL CANCELLED`, 왕관과 Phase 유지 |
| F6 강탈 시퀀스 | Crown, Spotlight, Alarm, Gate, Guard, Objective 순서 정상 |
| 시퀀스 중 F6 재입력 | 중복 실행되지 않음 |
| Gate 하강 | `CLOSING → CLOSED`, 출입구 충돌 활성화 |
| 18초 타이머 종료 | `ESCAPE`, `REACH THE EXIT`, Gate 재개방 |
| ESCAPE 상태에서 R | 모든 상태가 초기값으로 복원 |
| 콘솔 | 새 탭 경고·오류 0건 |
| 성능 안정 구간 | `FPS 165 · AVG 165 · LOW 115 · RENDER 87%` |

개발 서버에서 Babylon 셰이더 경로가 HTML로 대체되어 월드가 보이지 않던 문제도 발견했다. 셰이더 모듈 import에 `.js` 확장자를 명시해 개발 서버와 배포 빌드가 같은 파일을 사용하도록 고쳤다.
