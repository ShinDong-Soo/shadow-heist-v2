# 1~9단계 미완성 기능 보완 완료

이 문서는 기획안 1~9를 다시 대조해 **테스트 항목을 제외하고 실제로 빠져 있던 기능**을 정리한 기록이다. 코드를 처음 보는 개발자가 어떤 시스템끼리 연결됐는지 이해할 수 있도록 분야별로 나눈다.

## 경비 AI

경비는 이제 단순 순찰과 정지 반응에서 끝나지 않는다.

```text
PATROL
→ SUSPICIOUS
→ INVESTIGATE
→ SEARCH
→ PATROL 복귀

DETECTED
→ CHASE
→ 가까이 도달
→ CAPTURE / HEIST FAILED
```

- 플레이어를 놓치면 마지막으로 본 위치를 향한다.
- 조사 지점에 도착하면 약 4.2초간 좌우를 탐색한다.
- 조사 중 플레이어를 다시 보면 즉시 Chase로 전환한다.
- 장애물 정면에서 멈추면 양쪽 벽면 이동 후보를 비교해 우회한다.
- 찾지 못하면 현재 Alarm/Lockdown에 맞는 순찰 경로로 돌아간다.

## 은신

- 경비가 Locker 진입을 봤다면 Locker 위치를 기억한다.
- 경비가 Locker 앞까지 와서 약 1초간 확인한 뒤 문을 연다.
- 플레이어가 안에 있으면 `FOUND IN LOCKER` 실패가 된다.
- Lockdown 중 5.5초 이상 같은 Locker에 있으면 `LOCKDOWN_SWEEP`가 발생한다.
- 발견된 뒤에는 E로 빠져나와 실패 상태를 해제할 수 없다.

## 이동과 충돌

Player 충돌 높이는 자세에 따라 바뀐다.

| 자세 | 충돌 높이 | 탐지 목표 높이 |
|---|---:|---:|
| Stand / Walk / Run | 1.76m | 1.15m |
| Crouch / Crouch Walk | 1.08m | 0.72m |

충돌 상자에도 아래·위 높이를 기록한다. 따라서 이후 천장이 낮은 통로나 높은 바닥 장애물을 추가해도 같은 충돌 함수에서 자세 차이를 처리할 수 있다. 현재 낮은 전시대는 서 있으면 상체가 보이고 웅크리면 LOS가 차단되는 엄폐물 역할을 한다.

## 사운드와 청각

Player 발이 실제 이동 거리 기준 접촉 지점에 도달할 때 소음 이벤트를 만든다.

| 이동 | 기본 소음 반경 |
|---|---:|
| Crouch Walk | 0.8m |
| Walk | 2.6m |
| Run | 7.0m |

표면 보정은 Carpet 0.58배, Marble 1배, Metal 1.35배다. 반경 안의 Guard는 소리가 난 좌표를 조사한다. 경비 발소리는 제공된 `guard-footstep.mp3`를 사용하며 거리, 좌우 방향, 표면에 따라 음량·Pan·재생 속도가 달라진다. Chase에서는 재생 속도가 더 빠르고, 가까운 거리는 크고 먼 거리는 작게 들린다.

## 캐릭터와 상호작용

- Guard의 Investigate와 Search는 Patrol과 다른 상체·손전등 자세를 쓴다.
- Chase는 별도 달리기 보폭과 강한 발소리를 쓴다.
- Player Interact는 손이 닿기 전에 다시 원위치로 돌아오지 않는다.
- Hold E 완료 시 `CROWN_CONTACT` 이벤트가 발생한다.
- 왕관은 Player Root 앞 고정점이 아니라 실제 오른손 위치로 이동한다.

## 테스트와 외부 자산의 구분

사용자 요청에 따라 아래 항목은 이번 **기능 구현 범위**에서 제외했다.

- 공개 URL 배포
- Chrome·Edge 장시간 플레이 감각 확인
- 실제 PC 1080p 목표 FPS 판정
- 최종 Humanoid GLB 모델·Rig 교체

마지막 항목은 게임 로직 누락이 아니라 원본 3D 캐릭터 자산이 필요한 교체 작업이다. 현재 `CharacterVisual` 분리 구조 덕분에 나중에 GLB가 준비되면 충돌·AI·카메라 코드를 바꾸지 않고 시각 모델만 교체할 수 있다.
