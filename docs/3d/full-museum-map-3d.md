# 11단계 — 박물관 전체 3D 맵

이 문서는 지금까지 따로 만들었던 3D 기능을 **처음부터 끝까지 플레이할 수 있는 하나의 박물관 맵**으로 합친 내용을 설명한다.

개발을 처음 접하는 사람은 먼저 다음 흐름만 기억하면 된다.

```text
서비스 입구
→ 서관 회화실
→ 조각 홀
→ 기록 보관실
→ 보안 복도
→ 왕관실
→ 왕관 강탈과 봉쇄
→ 비상 통로
→ 탈출
```

## 1. 맵과 구역

맵은 하나의 거대한 모델이 아니라 벽, 바닥, 기둥, 선반, 전시대 같은 작은 부품을 조합하는 방식으로 만들었다. 이 방식을 **모듈러 방식**이라고 한다. 수정하기 쉽고 같은 부품을 재사용할 수 있어 웹게임 성능에도 유리하다.

### 서비스 입구

- 플레이어 시작 위치다.
- 경비원을 바로 마주치지 않고 이동과 카메라 조작을 익힌다.
- 서비스 문, 비상등, CCTV를 배치해 몰래 침입하는 분위기를 만든다.

### 서관 회화실

- 따뜻한 색의 카펫, 대형 황금 액자, 전시 벤치가 Landmark 역할을 한다.
- Guard A가 회화실과 조각 홀 사이를 순찰한다.
- 전시 파티션과 기둥 뒤로 이동하며 손전등 방향을 읽는다.
- 최단 동선에서 조금 벗어난 곳에 `ANTIQUE WATCH`가 있다.

### 조각 홀

- 차가운 대리석 바닥, 큰 조각상, 굵은 기둥으로 회화실과 다르게 보인다.
- 큰 오브젝트는 장식이 아니라 실제 LOS 차단과 엄폐물로 작동한다.
- 경비원 본체가 보이기 전에 손전등과 그림자를 먼저 볼 수 있는 공간을 목표로 설계했다.

### 기록 보관실

- 4줄의 높은 문서 선반이 경비원의 LOS를 막는다.
- 좁은 선반 통로 때문에 조각 홀과 다른 잠입 방식이 필요하다.
- 직원용 Locker에 `E`로 들어가 숨을 수 있다.
- Guard B가 선반 통로, Locker 앞, 서류 확인 지점을 순찰한다.
- `ROYAL DOCUMENT`를 추가 선택 보물로 배치했다.

### 보안 복도

- 왕관실 직전의 짧고 위험한 연결 구역이다.
- 붉은 보안 문과 센서가 강한 Landmark 역할을 한다.
- 경비원을 더 늘리는 대신 회전 CCTV 2대와 긴 직선 LOS를 사용한다.

### 왕관실

- 기존 5~10단계에서 검증한 왕관, 전시대, 기둥, Locker, 보안 게이트를 전체 맵 북쪽 끝에 연결했다.
- 복도에서 왕관 Spotlight가 일부 보여 UI 없이도 목표 위치를 알 수 있다.

### 비상 통로와 출구

- 왕관 획득 전에는 잠겨 있다.
- Lockdown이 끝나면 Archive 동쪽의 짧고 좁은 서비스 통로가 열린다.
- 시작 지점과 다른 동쪽 비상 출구를 통과하면 `HEIST COMPLETE`가 된다.

## 2. 플레이 흐름과 목표

`GameFlowManager`가 전체 강도 작전의 순서를 관리한다.

```text
INFILTRATION
→ CROWN_STEAL
→ ALARM
→ LOCKDOWN
→ ESCAPE
→ COMPLETE
```

- 시작 목표는 `FIND THE CROWN HALL`이다.
- 왕관실에 들어가면 `STEAL THE CROWN`으로 바뀐다.
- 왕관을 훔치면 맵 전체 경보와 Lockdown이 시작된다.
- Lockdown 종료 후 비상 통로와 최종 출구가 열린다.
- 출구 Trigger를 통과하면 플레이어 이동을 잠그고 완료 문구를 표시한다.
- 체포되면 `R` 한 번으로 페이지 새로고침 없이 처음부터 재시작한다.

## 3. 플레이어와 카메라

- 플레이어 시작점은 서비스 입구다.
- `W`를 누르면 화면 위쪽, 즉 박물관 안쪽으로 이동하도록 카메라 방향을 맞췄다.
- 카메라는 플레이어를 매 프레임 딱 붙어 따라가지 않고 완충 구역과 부드러운 보간을 사용한다.
- 카메라를 가리는 남쪽 벽은 낮게 만드는 Cutaway 방식을 적용했다.
- 가까운 벽, 이동 가능한 길, 엄폐물과 Landmark는 어둠 속에서도 알아볼 수 있게 남겼다.
- Escape 단계에서는 진행 방향을 약 1.7m 먼저 바라보고 시야 범위를 넓힌다.
- 특히 남쪽으로 달릴 때 플레이어가 화면 위쪽에 놓여 아래쪽 경비원과 손전등을 더 일찍 확인할 수 있다.

## 4. 경비원과 AI

경비원은 두 명이다.

- Guard A: 서관 회화실 ↔ 조각 홀
- Guard B: 기록 보관실 ↔ 보안 복도

각 경비원은 다음 FSM을 독립적으로 사용한다.

```text
PATROL
→ SUSPICIOUS
→ INVESTIGATE
→ SEARCH
→ RETURN

플레이어 확정 발견 시
→ CHASE
→ CAPTURE
```

왕관 경보가 울리면 평소 순찰 경로 대신 중앙 통로, 왕관실, Archive, 출구 방향의 경보용 경로를 사용한다.

구역 사이 장거리 이동에는 문과 복도 중앙을 잇는 **Portal 경유점**을 사용한다. 경비원이 벽을 향해 직진하거나 좁은 선반에 계속 끼이지 않도록 중간 목표를 자동 생성한다.

Guard A가 플레이어를 보면 Guard B에게 현재 위치가 아니라 `Reported Position`을 전송한다. 다른 경비원은 그 지점을 조사한 뒤 주변을 수색한다.

## 5. 손전등, LOS, CCTV

### 경비원 손전등

- 경비원의 몸 방향과 손전등 방향을 동기화했다.
- 벽, 기둥, 조각상, 선반은 `blocksVision` 속성으로 Ray를 차단한다.
- 손전등 그림자와 LOS가 같은 장애물을 기준으로 판단한다.

### CCTV

- 보안 복도에 회전 CCTV 2대를 배치했다.
- 탐지 거리는 7m이며, 카메라가 바라보는 부채꼴 안에 있을 때만 감지한다.
- 카메라와 플레이어 사이에 벽이 있으면 Ray가 차단되어 감지하지 않는다.
- 확정 탐지 시 Guard B는 `CCTV_ALARM`, Guard A는 `RADIO_CCTV_REPORT` 위치를 조사한다.
- 이미 의심 중인 경비원이 CCTV 보고를 무시하던 우선순위 문제를 수정했다.

## 6. 엄폐와 Locker 은신

- 조각상, 기둥, 전시 파티션, 선반은 버튼 없이 실제 Geometry 뒤에 숨는 자연 엄폐다.
- Archive와 Crown Hall의 Locker는 전용 은신처다.
- Locker 진입 시 탑다운 전체 화면 대신 내부 관찰 틈 시점으로 전환된다.
- 플레이어는 움직일 수 없고 가장 가까운 경비원의 발소리 방향과 거리를 듣는다.
- 경비원이 들어가는 장면을 봤거나 Lockdown 중 한곳에 너무 오래 숨으면 Locker를 조사할 수 있다.

## 7. 선택 보물

메인 왕관 외에 세 개를 배치했다.

| 보물 | 위치 | 가치 |
| --- | --- | ---: |
| ANTIQUE WATCH | 서관 회화실 | ₩1,200,000 |
| DIAMOND BROOCH | 조각 홀 | ₩2,800,000 |
| ROYAL DOCUMENT | 기록 보관실 | ₩2,000,000 |

보물은 최단 경로에서 약간 벗어나 있다. `E`로 획득하면 하단의 획득 수와 금액이 즉시 바뀌고, 작은 금속 소음이 발생해 주변 경비원이 조사할 수 있다.

## 8. 경보, Lockdown, 탈출

- 왕관 획득 시 왕관실만이 아니라 모든 구역의 경보 Beacon이 켜진다.
- 실제 동적 붉은 조명을 많이 만들지 않고 Emissive 재질을 사용해 비용을 줄였다.
- 두 경비원 모두 Alert 속도와 경로로 전환한다.
- Last Known Position, Search Point, Locker 조사로 한 장소에서 기다리는 플레이를 압박한다.
- Lockdown 종료 시 왕관실 Gate와 Archive 동쪽 Shortcut이 열린다.
- 목표 문구가 `ESCAPE VIA ARCHIVE EAST`로 바뀌어 어느 방향으로 가야 하는지 알려준다.
- Archive 동쪽 문부터 최종 출구까지 청록색 삼각 유도등이 순서대로 켜진다.
- Archive 동쪽 비상구는 상시 보이는 산업용 문틀과 셔터로 표현한다. 문 앞 바닥 표지는 `EMERGENCY EXIT / LOCKED` 또는 `OPEN`을 직접 표시하고, 셔터의 붉은 잠금선과 청록색 개방선도 상태에 맞춰 바뀐다.
- 최종 출구를 통과하면 경보를 끄고 `HEIST COMPLETE`로 종료한다.

탈출 중 경비원은 평상시보다 손전등을 약 30% 멀리 비춘다. 발소리도 최대 13m부터 희미하게 들리므로 경비원 본체가 화면 가장자리에 나타나기 전에 위험을 먼저 추측할 수 있다.

## 9. 조명과 구역별 시각 정체성

모든 공간이 같은 Graybox처럼 보이지 않도록 색, 바닥, Landmark를 다르게 했다.

- Entrance: 서비스 회색과 비상등
- West Gallery: 목재, 금색 액자, 카펫
- Sculpture Hall: 대리석, 조각상, 긴 그림자
- Archive: 청록 형광등, 금속 선반과 캐비닛
- Security Corridor: 붉은 보안 장치와 금속 통로
- Crown Hall: 검정·금색과 강한 왕관 Spotlight
- Escape Route: 좁은 산업용 통로와 비상 표시

어둠은 길을 못 보게 만드는 용도가 아니라 멀리 있는 경비원의 정확한 위치를 숨기는 데 사용한다.

## 10. UI

- 구역 이름, 선택 보물 수와 총액, 현재 목표를 간단히 표시한다.
- 탈출 단계에서는 중앙 상단의 `OPEN / GATE OPEN` 패널을 제거한다. 남은 목표는 왼쪽 임무 정보 아래에 작게 배치해 남쪽 탈출 경로와 경비원 시야를 가리지 않는다.
- 상세 미니맵은 넣지 않았다. Landmark와 공간 구조로 길을 찾게 한다.
- 개발 정보는 기본으로 숨기고 `F2`를 눌렀을 때만 표시한다.
- 이전 2D 프로토타입으로 이동하는 링크는 제출 화면에서 제거했다. `TEST KEYS`와 디버그 단축키는 개발 서버에서만 제공한다.
- 완료·실패 상태에서는 다음 행동을 한 문장으로 안내한다.

## 11. 웹 성능 처리

- 동일한 바닥, 기둥, 선반 재질을 공유한다.
- 움직이지 않는 Mesh는 World Matrix를 고정한다.
- 작은 장식물은 그림자 대상에서 제외하고 플레이어, 경비원, 큰 기둥과 조각상 위주로 그림자를 만든다.
- 경보등은 Emissive 중심으로 처리한다.
- 평균 FPS에 따라 내부 렌더 해상도를 자동 조절한다.
- 현재 전체 맵은 약 276 Mesh로 구성된다.
- 프로덕션 빌드는 성공했다. Babylon.js 엔진 Chunk가 500kB를 넘는 경고는 남아 있지만 실행 오류는 아니다.

## 14. 직접 플레이로 남은 검수

아래 항목은 기능 구현이 아니라 사람의 실제 플레이 감각을 확인하는 단계다.

- 첫 플레이가 7~12분 안에 끝나는지 5회 측정
- 숙련 플레이가 4~7분인지 측정
- Chrome, Edge, 시크릿 창에서 각각 처음부터 끝까지 완주
- 배포한 웹 주소를 로그인 없이 직접 열 수 있는지 확인
- 처음 보는 사람이 길을 잃지 않는지 외부 플레이 테스트
- 실제 PC에서 1080p 평균 FPS와 1% Low 측정
- 결과에 따라 경비 속도, 대기 시간, Cover 간격을 최종 조정

이 검수가 끝나기 전에는 플레이 시간과 체감 난이도를 “완료”로 기록하지 않는다.
