# 3D 경보와 봉쇄 — Phase 07

이 문서는 왕관을 훔친 뒤의 18초를 단순한 대기 시간이 아니라 **계속 위치를 바꿔야 하는 위험 구간**으로 만든 방법을 설명한다.

## 플레이 흐름

```text
INFILTRATION
→ CROWN_STEAL
→ ALARM: 경고음·적색등·셔터 하강 시작
→ LOCKDOWN: 18초 동안 경비 수색 구역 변화
→ ESCAPE: 셔터가 열리고 남쪽 출구 표시
```

`ALARM`과 `LOCKDOWN`은 서로 다른 단계다. 경보는 보안 침입이 감지된 짧은 전환이고, 봉쇄는 플레이어가 실제로 버텨야 하는 게임 구간이다.

## 담당 코드

| 파일 | 역할 |
|---|---|
| `core/GamePhase.ts` | `ALARM`을 포함한 전체 게임 단계 이름 |
| `core/GameFlowManager.ts` | 단계 전환과 시스템 사이의 이벤트 전달 |
| `systems/AlarmSystem.ts` | 경고 상태, 적색등, 경보음, 5초 틱, 해제음 |
| `systems/LockdownSystem.ts` | 18초 타이머, 봉쇄 상태와 세 구간의 위험 변화 |
| `systems/SecurityGate.ts` | 하강·폐쇄·개방, 충돌과 끼임 방지 |
| `entities/guard/GuardController.ts` | 구간별 순찰 경로와 정지 스캔 |
| `entities/guard/GuardVision.ts` | 경보 중 15% 증가한 탐지 거리 |

## 상태와 이벤트

Alarm 상태는 `INACTIVE → TRIGGERING → ACTIVE` 순서로 바뀐다. Lockdown 상태는 다음 순서다.

```text
INACTIVE → STARTING → ACTIVE → RELEASING → COMPLETE
```

다른 시스템이 다음 단계에서 쉽게 연결되도록 네 이벤트를 외부에 공개한다.

- `ALARM_STARTED`
- `LOCKDOWN_STARTED`
- `LOCKDOWN_ENDED`
- `ESCAPE_AVAILABLE`

## 18초 동안 달라지는 위험

경비가 같은 길만 반복하면 플레이어는 안전한 기둥 뒤에서 기다리게 된다. 이를 막기 위해 남은 시간에 따라 경비 경로가 세 번 바뀐다.

| 진행 시간 | 위험 구역 | 플레이 의미 |
|---:|---|---|
| 0~6초 | `CROWN_SWEEP` | 왕관 주변을 떠나야 한다. |
| 6~12초 | `WEST_SWEEP` | 안전 경로와 중앙 엄폐가 압박받는다. |
| 12~18초 | `EXIT_SWEEP` | 출구 근처를 미리 점유하기 어렵다. |

경비는 ALERT 속도로 이동하고 웨이포인트에서 손전등을 좌우로 훑는다. 경보 중 시야 거리는 평상시 8m에서 9.2m로 증가한다.

## 게이트 끼임 방지

셔터는 실제로 플레이어 높이까지 내려온 시점부터 충돌한다. 플레이어가 문턱 안에 있을 때는 셔터 진행을 잠시 멈춘다.

```text
플레이어가 문턱 밖
→ 셔터 정상 하강

플레이어가 문턱 안
→ PLAYER HOLD
→ 셔터 일시 정지
→ 플레이어가 빠져나가면 다시 하강
```

따라서 캐릭터 위에 충돌 영역이 갑자기 생기거나 양쪽 공간 사이에 갇히지 않는다. 18초가 끝나면 셔터가 올라가고 충돌 영역도 함께 사라진다.

## UI와 사운드

- ALARM 단계에는 `SECURITY BREACH`와 `ALERT`가 표시된다.
- LOCKDOWN에는 현재 남은 시간과 게이트 상태가 표시된다.
- 5초부터 패널이 붉게 맥동하고 매초 짧은 틱 소리가 난다.
- 종료 시 상승하는 해제음과 `EXIT UNLOCKED`가 재생된다.
- ESCAPE에서는 화면 아래에 `EXIT OPEN ↓ SOUTH GATE`가 표시된다.
- 경고등은 왕관실·연결 통로·출구에 배치하되 실제 동적 Point Light는 2개만 사용한다.

## 테스트 방법

1. `npm run dev`를 실행하고 `/3d.html`을 연다.
2. `F6`을 눌러 왕관 강탈 시퀀스를 바로 시작한다.
3. 디버그의 `FLOW`, `EVENT`, `ALARM`, `LOCK`, `GATE`를 확인한다.
4. 경비가 왕관 → 서쪽/중앙 → 출구 순서로 압박하는지 확인한다.
5. 기다리지 않으려면 `F7`을 눌러 남은 시간을 5초로 만든다.
6. 남은 5초에 UI와 틱 소리가 강해지는지 확인한다.
7. 종료 후 셔터와 남쪽 출구 표시를 확인한다.
8. `R`을 눌러 모든 값이 초기화되는지 확인한다.

자동 브라우저는 WebGL이 약 4FPS로 제한되어 Delta Time 안전 제한 때문에 18초 타이머도 느리게 진행될 수 있다. 최종 체감과 60FPS 성능은 일반 Chrome의 활성 탭에서 확인해야 한다.
