# Shadow Heist V2 3D 개발 문서

이 폴더는 Shadow Heist V2의 **부분 3D 실험과 Babylon.js 기반 전체 3D 전환 작업**만 따로 모아 보관한다.

처음 보는 개발자는 아래 순서대로 읽으면 된다.

1. [부분 3D 전환](partial-3d.md) — 기존 2D 게임에서 보물 획득 장면만 3D로 시험한 초기 단계
2. [Babylon.js 3D 기반](babylon-3d-foundation.md) — 별도 3D 진입점과 엔진 구조를 만든 1단계
3. [3D 플레이어 이동과 탑다운 카메라](player-movement-3d.md) — 이동·충돌·카메라를 만든 2단계
4. [3D 1·2단계 완료 현황](3d-phase-status.md) — 1·2단계 기획안 체크리스트와 검증 결과
5. [3D 경비 순찰과 손전등](guard-patrol-3d.md) — 경비 순찰과 조명을 만든 3단계
6. [3D LOS와 플레이어 탐지](guard-vision-3d.md) — 시야·벽 차폐·탐지 게이지를 만든 4단계
7. [3D 왕관실과 왕관 상호작용](crown-hall-3d.md) — 잠입 퍼즐 공간, 전시대, 엄폐, 왕관 획득 이벤트를 만든 5단계
8. [3D 왕관 강탈 시퀀스](crown-steal-sequence-3d.md) — Hold E, 경보, 셔터, 경비 ALERT와 탈출 전환을 만든 6단계
9. [3D 경보와 봉쇄](alarm-lockdown-3d.md) — 경보 상태, 18초 구역별 압박, 게이트 안전과 탈출 안내를 만든 7단계
10. [3D 은신 시스템](hiding-3d.md) — 자연 엄폐, 기록 선반, Locker 진입·이탈과 접근 사운드를 만든 8단계
11. [3D 캐릭터 애니메이션](character-animation-3d.md) — 관절형 캐릭터, 이동 거리 기반 보행, 상태별 몸짓과 발소리를 만든 9단계
12. [미완성 기능 보완 완료](remaining-plan-completion.md) — 테스트 항목을 제외하고 1~9단계의 남은 기능을 다시 대조한 결과
13. [3D Guard AI FSM](guard-ai-fsm-3d.md) — 기억·청각·조사·추격·수색·복귀를 포함한 10단계 경비 AI 이식
14. [3D 박물관 전체 맵](full-museum-map-3d.md) — 7개 구역, 경비원 2명, CCTV, 선택 보물, 전체 경보와 비상 탈출을 통합한 11단계

## 문서 관리 방법

- 새로운 3D 단계 문서는 이 폴더에 추가한다.
- 파일 이름은 기능을 알 수 있는 영문 소문자와 하이픈으로 작성한다.
- 단계별 구현 내용은 해당 문서에 기록하고, 전체 변경 요약만 상위 [변경 이력](../changelog.md)에 기록한다.
- 아직 구현하지 않은 기능은 완료로 표시하지 않고 `남음` 또는 `범위 밖`으로 구분한다.
