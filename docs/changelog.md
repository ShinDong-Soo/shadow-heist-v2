# 변경 이력

이 문서는 각 프로토타입에서 크게 바뀐 분야만 기록한다. 기능의 상세한 현재 동작은 [개발 문서 목차](README.md)의 담당 문서에서 관리한다.

## Prototype 29

변경 분야:

- 열린 문 통로에서 상체·머리 보조 충돌 원이 양옆 벽을 동시에 잡던 문제 수정
- 문 안에서는 발 충돌을 유지하고 상체 보조 충돌만 해제해 자연스러운 통과 폭 확보
- 닫힌 문과 일반 벽에는 기존 몸 전체 충돌을 유지해 캐릭터 이미지 겹침 방지

관련 문서:

- [플레이어와 조작](player-and-controls.md#충돌)

## Prototype 28

변경 분야:

- 별도 Shift 조심 걷기를 제거하고 기본 이동을 저소음 잠입 걷기로 변경
- Shift를 빠르지만 소음 반경이 큰 달리기로 변경해 안전과 속도의 선택을 명확하게 구성
- 조명 스위치를 4초 대기 후 다시 조작할 수 있는 구역 교란 장치로 확장
- 정전 구역에서 경비의 실제 유효 시야를 약 50~65%, 플레이어 시야를 78%로 축소
- 조명 변화 시 범위 안에서 가장 가까운 경비 한 명이 스위치 위치를 조사하도록 연결
- 플레이테스트 기록에 기본 걷기·달리기 시간과 조명 조사 횟수 추가

관련 문서:

- [플레이어와 조작](player-and-controls.md)
- [사운드](audio.md)
- [맵, 시야, 조명](map-vision-lighting.md)
- [경비원 AI](guard-ai.md)
- [플레이테스트](playtest.md)

## Prototype 27

변경 분야:

- 현재 플레이어 LOS 밖을 완전한 불투명 어둠으로 덮어 맵 윤곽 노출 차단

- 경비·보물·CCTV 등 동적 정보도 기존처럼 현재 LOS 안에서만 표시
