# UI와 그래픽

> 플레이어와 경비원의 외형, 이미지 파일, 교체 방법은 [캐릭터 에셋](characters.md)에서 관리한다.

## 첫 플레이 온보딩

- 시작 지점에서 기본 이동, 위험한 달리기, 경비 발소리 읽기, 첫 보물 획득을 네 단계로 안내한다.
- 설명을 읽는 것만으로 넘어가지 않고 실제 이동 거리, Shift 달리기 사용 시간, 첫 위험음, 첫 보물 획득을 확인한 뒤 다음 단계로 진행한다.
- 첫 보물을 얻으면 기본 온보딩을 끝내고 상단의 위험·보상 선택 연출로 넘긴다.

## 경비 행동 원인 표시

- 경비가 상태를 바꿀 때 머리 위에 원인을 약 1.9초 동안 표시한다.
- 예: `큰 발소리 감지`, `문 소리 감지`, `무전 위치 확인`, `시야 상실 · 마지막 위치`.
- 이 표시는 현재 플레이어 시야 안에서만 렌더링되므로 보이지 않는 경비의 정확한 위치를 공짜로 공개하지 않는다.

이 문서는 시작 화면, HUD, 결과 화면, 캐릭터와 박물관의 시각 표현을 설명한다.

## 시작 화면

- 게임의 핵심 목표를 설명한다.
- 현재 하이스트 번호, 이름과 이번 판에 추가되는 위험을 설명한다.
- WASD 저소음 이동, Shift 달리기, C 웅크리기, E 상호작용을 안내한다.
- `잠입 시작` 버튼으로 게임을 시작한다.
- 버튼 입력은 브라우저 오디오 활성화에도 사용한다.

## 플레이 HUD

### 상단

- 게임 로고와 프로토타입 버전
- 현재 목표
- 현재 안전 상태: `미탐지`, `위험 감지`, `발각`만 표시하며 순찰·조사·수색 같은 정확한 AI 상태는 숨긴다.

### 왼쪽 하단

- `LISTEN · 헤드폰 권장` 안내만 표시한다.
- 경비의 방향 화살표와 거리 막대는 표시하지 않는다. 두 경비의 실제 공간 음향을 듣고 판단하게 하기 위한 선택이다.

### 오른쪽 하단

- 확보한 보물 수
- 현재 확보 점수
- 현재 출입 권한
- 현재 맵 탐색률
- 플레이어 노출도
- 플레이어 이동 소음
- 전역 경계 레벨

일곱 항목은 고정 7열 정보판 안에 배치한다. 항목마다 최소 폭을 확보하고 반투명 배경과 위쪽 구분선을 사용해 글자가 서로 포개지지 않게 한다. `SECURITY ALERT` 분위기 문구는 이 정보판과 겹치지 않도록 화면 오른쪽 상단에 표시한다.

### 중앙 하단

가까운 상호작용 대상을 표시한다.

- 보물 이름과 점수
- 문, 은신처, 키카드와 CCTV 제어반 사용
- 현재 점수를 확보하고 탈출하기

### 은신 전용 화면

- 전체 HUD 대신 `[E] 나오기`와 오른쪽 아래 `ALERT`만 남긴다.
- 은신처 종류에 따라 세로 문틈, 커튼 이음새 또는 낮은 가로 틈을 표시한다.
- 청각 파동은 가장 가까운 경비가 있는 화면 상하좌우 방향에 나타나며, 가까울수록 더 크고 밝고 빠르다.
- 나가기 안내는 설비 이름을 반복하지 않고 `[E] 나오기`만 표시한다.
- 경비가 매우 가깝거나 은신처를 확인 중이면 나가기 안내 아래에 `위험`을 표시한다.

### 첫 보물 선택 연출

첫 보물을 획득하면 약 3.2초 동안 화면 상단에 다음 내용을 표시한다.

- 현재 확보 점수
- 지금 출구로 돌아갈 수 있다는 선택
- 다음 보물까지 도전할 때 적용될 점수 배수
- 체포되면 이번 판 점수를 모두 잃는다는 경고

게임을 멈추는 창은 아니므로 연출이 떠 있는 동안에도 이동할 수 있다. 플레이어에게 결정을 강요하는 메뉴가 아니라 이미 존재하는 선택을 알아차리게 하는 안내다. 경비가 추격을 시작하거나 감지율이 72% 이상으로 올라가면 시야를 가리지 않도록 즉시 사라진다.

### 출구 봉쇄 경고

- 화면 상단에 `EXIT LOCKDOWN`과 남은 시간을 표시한다.
- 봉쇄된 출구는 붉은색 차단봉과 남은 시간으로 표시한다.
- 봉쇄가 해제되면 출구가 다시 초록색으로 바뀐다.

## 결과 화면

- 탈출 성공 또는 체포
- 확보한 보물 수
- 최종 점수
- 플레이 시간
- 발각 횟수
- 최고 감지율
- 추격 시간
- 잠입 보너스
- 현재 하이스트의 최고 점수
- 성공 시 다음 하이스트 버튼. 세 번째 하이스트에서는 표시하지 않는다.
- 다시 시작 버튼

## 개발자 패널

- F2로 열고 닫는다.
- 오른쪽에 실시간 게임 상태와 최근 플레이 결과를 표시한다.
- 경비 경로와 소음 파동의 디버그 표시를 선택할 수 있다.
- 일반 플레이 UI보다 위에 표시되며 작은 화면에서는 화면 여백에 맞춰 확장된다.

사용법과 수치 설명은 [플레이테스트 도구와 밸런스](playtest-tools.md)에서 관리한다.

## 화면 크기 대응

- Canvas는 브라우저 창 크기에 맞춰 확대하거나 축소한다.
- 내부 게임 좌표는 고정되어 화면 크기가 달라도 이동 규칙은 같다.
- 작은 화면에서는 목표와 하단 HUD의 위치를 조정한다.

## 캐릭터 표현

### 플레이어

- 청록색 계열
- 이동 방향에 맞춘 몸과 시선 회전
- 속도에 따른 다리 움직임
- 웅크릴 때 낮아지는 실루엣과 약해지는 빛 효과
- 보물 소지 시 가방 표시

### 경비원

- 순찰: 황금색
- 의심과 조사: 주황색 및 `?`
- 수색: 주황색 및 `…`
- 추격: 붉은색과 강한 빛
- 이동 상태에 따른 다리 움직임
- 알파의 기본 순찰색은 황금색, 브라보는 청회색

## 은신 표현

- 종류별 은신처를 벽면 커튼, 사각형 조각 전시대, 직원용 보관함, 높은 기록 선반으로 그린다.
- 은신처는 주변 벽이나 기존 전시 설비에 붙여 배치하고 물리 크기와 접근 면을 표시한다.
- 은신 중 플레이어 캐릭터를 표시하지 않는다.
- 화면 가장자리를 어둡게 하고 가로 틈을 표시한다.
- 경비 접근 거리에 따라 붉은 압박 효과를 조절한다.
- 경비가 확인하러 오는 은신처는 붉은색으로 강조한다.

은신의 실제 게임 규칙은 [숨기 시스템](hiding.md)에서 관리한다.

## Fake 2.5D 박물관

실제 3D 모델을 사용하지 않고 2D 도형에 옆면과 그림자를 추가한다.

- 벽과 전시대에 상단, 앞면, 오른쪽 면 표시
- 오브젝트 뒤쪽의 그림자
- 벽과 전시대의 상단·앞면·옆면을 기본 오브젝트 단계에서 한 번만 그리는 깊이 표현
- 구역별 바닥 패턴과 테두리
- 전시대의 유리 느낌
- 보물별 고유 모양, 색상, 빛 효과
- 열린 문은 복도로 회전하지 않고 문틀 안으로 수납되는 슬라이딩 패널
- 조명 단말은 바닥형 물리 장치, CCTV 제어반은 통로를 막지 않는 벽 부착형 물리 장치
- 시작 구역의 입·출구는 금속 쌍문, 문틀, 비상 표지, 상태등, 바닥 매트로 표현

출구는 바닥의 점선 사각형이 아니다. 보물을 얻기 전에는 `LOOT REQUIRED`, 탈출 가능 상태에서는 녹색 안내광, 봉쇄 중에는 붉은 보안 셔터와 남은 시간을 표시한다.

캐릭터를 그린 뒤 모든 벽 앞면을 다시 덮어 그리는 방식은 사용하지 않는다. 그 방식은 캐릭터가 벽 아래쪽에 있어도 몸 중앙이 가로로 잘리는 결과를 만들기 때문이다. 벽의 입체 면은 `drawObjects()` 단계에서 한 번만 그려 캐릭터 실루엣을 온전히 유지한다.

## 경비 시야 표현

- 경비원 앞쪽에 부채꼴 시야를 그린다.
- 중앙에는 더 밝고 좁은 손전등 중심광을 표시한다.
- 평상시, 의심, 추격 상태에 따라 색과 범위가 달라진다.
- 추격 시작 시 화면 가장자리와 화면 전체에 짧은 붉은 경고를 표시한다.

## CCTV 표현

- CCTV 본체와 렌즈가 현재 감시 방향으로 회전한다.
- 평상시 시야는 청백색, 감지 중에는 노란색, 경보 시에는 붉은색이다.
- 비활성화된 CCTV는 회색으로 표시하고 복구까지 남은 시간을 보여준다.
- 화면 상단에 현재 가장 높은 CCTV 감지 진행률을 표시한다.
- CCTV 제어반은 벽에 붙은 얇은 함체로 표시하며 사용 전과 사용 후의 색이 다르다.

실제 탐지 규칙은 [CCTV](cctv.md)에서 관리한다.

## 직접 확인할 것

- HUD가 플레이 공간을 지나치게 가리지 않는가?
- 경계와 노출 상태를 빠르게 이해할 수 있는가?
- 정지, 저소음 걷기, 달리기, 웅크리기의 소음 단계를 HUD로 구분할 수 있는가?
- 웅크린 자세가 일반 이동과 즉시 구분되는가?
- 캐릭터 색과 아이콘만으로 경비 상태를 구분할 수 있는가?
- 벽과 캐릭터의 앞뒤 관계가 어색하지 않은가?
- 문과 제어 장치가 캐릭터나 서로의 위에 겹쳐 보이지 않는가?
- 입·출구가 바닥 표식이 아니라 실제 건물 출입구처럼 보이는가?
- 작은 화면에서도 주요 정보가 겹치지 않는가?
- CCTV 경고와 출구 봉쇄 경고를 서로 구분할 수 있는가?
- 현재 시야 밖의 맵 형태가 완전히 가려지는가?
