# UI와 그래픽

이 문서는 시작 화면, HUD, 결과 화면, 캐릭터와 박물관의 시각 표현을 설명한다.

## 시작 화면

- 게임의 핵심 목표를 설명한다.
- WASD, Shift, E 조작을 안내한다.
- `잠입 시작` 버튼으로 게임을 시작한다.
- 버튼 입력은 브라우저 오디오 활성화에도 사용한다.

## 플레이 HUD

### 상단

- 게임 로고와 프로토타입 버전
- 현재 목표
- 경비원 상태

### 왼쪽 하단

- 경비원 접근음 크기
- 가장 가까운 경비원이 플레이어 기준 왼쪽 또는 오른쪽에 있는지 표시

### 오른쪽 하단

- 확보한 보물 수
- 현재 확보 점수
- 현재 출입 권한
- 현재 맵 탐색률
- 플레이어 노출도
- 플레이어 이동 소음
- 전역 경계 레벨

### 중앙 하단

가까운 상호작용 대상을 표시한다.

- 보물 이름과 점수
- 조명 스위치 켜기 또는 끄기
- 현재 점수를 확보하고 탈출하기

### 출구 봉쇄 경고

- 화면 상단에 `EXIT LOCKDOWN`과 남은 시간을 표시한다.
- 봉쇄된 출구는 붉은색 차단봉과 남은 시간으로 표시한다.
- 봉쇄가 해제되면 출구가 다시 초록색으로 바뀐다.

## 결과 화면

- 탈출 성공 또는 체포
- 확보한 보물 수
- 최종 점수
- 플레이 시간
- 발각 횟수
- 최고 감지율
- 추격 시간
- 다시 시작 버튼

## 개발자 패널

- F2로 열고 닫는다.
- 오른쪽에 실시간 게임 상태와 최근 플레이 결과를 표시한다.
- 경비 경로와 소음 파동의 디버그 표시를 선택할 수 있다.
- 일반 플레이 UI보다 위에 표시되며 작은 화면에서는 화면 여백에 맞춰 확장된다.

사용법과 수치 설명은 [플레이테스트 도구와 밸런스](playtest-tools.md)에서 관리한다.

## 화면 크기 대응

- Canvas는 브라우저 창 크기에 맞춰 확대하거나 축소한다.
- 내부 게임 좌표는 고정되어 화면 크기가 달라도 이동 규칙은 같다.
- 작은 화면에서는 목표와 하단 HUD의 위치를 조정한다.

## 캐릭터 표현

### 플레이어

- 청록색 계열
- 이동 방향에 맞춘 몸과 시선 회전
- 속도에 따른 다리 움직임
- 웅크릴 때 낮아지는 실루엣과 약해지는 빛 효과
- 보물 소지 시 가방 표시

### 경비원

- 순찰: 황금색
- 의심과 조사: 주황색 및 `?`
- 수색: 주황색 및 `…`
- 추격: 붉은색과 강한 빛
- 이동 상태에 따른 다리 움직임
- 알파의 기본 순찰색은 황금색, 브라보는 청회색

## 은신 표현

- 종류별 은신처를 커튼, 전시대, 보관함, 기록 보관 공간으로 그린다.
- 은신 중 플레이어 캐릭터를 표시하지 않는다.
- 화면 가장자리를 어둡게 하고 가로 틈을 표시한다.
- 경비 접근 거리에 따라 붉은 압박 효과를 조절한다.
- 경비가 확인하러 오는 은신처는 붉은색으로 강조한다.

은신의 실제 게임 규칙은 [숨기 시스템](hiding.md)에서 관리한다.

## Fake 2.5D 박물관

실제 3D 모델을 사용하지 않고 2D 도형에 옆면과 그림자를 추가한다.

- 벽과 전시대에 상단, 앞면, 오른쪽 면 표시
- 오브젝트 뒤쪽의 그림자
- 벽 전면이 가까운 캐릭터 일부를 가리는 깊이 표현
- 구역별 바닥 패턴과 테두리
- 전시대의 유리 느낌
- 보물별 고유 모양, 색상, 빛 효과

## 경비 시야 표현

- 경비원 앞쪽에 부채꼴 시야를 그린다.
- 중앙에는 더 밝고 좁은 손전등 중심광을 표시한다.
- 평상시, 의심, 추격 상태에 따라 색과 범위가 달라진다.
- 추격 시작 시 화면 가장자리와 화면 전체에 짧은 붉은 경고를 표시한다.

## CCTV 표현

- CCTV 본체와 렌즈가 현재 감시 방향으로 회전한다.
- 평상시 시야는 청백색, 감지 중에는 노란색, 경보 시에는 붉은색이다.
- 비활성화된 CCTV는 회색으로 표시하고 복구까지 남은 시간을 보여준다.
- 화면 상단에 현재 가장 높은 CCTV 감지 진행률을 표시한다.
- CCTV 제어반은 사용 전과 사용 후의 색이 다르다.

실제 탐지 규칙은 [CCTV](cctv.md)에서 관리한다.

## 직접 확인할 것

- HUD가 플레이 공간을 지나치게 가리지 않는가?
- 경계와 노출 상태를 빠르게 이해할 수 있는가?
- 정지, 조심 걷기, 일반 걷기의 소음 단계를 HUD로 구분할 수 있는가?
- 웅크린 자세가 일반 이동과 즉시 구분되는가?
- 캐릭터 색과 아이콘만으로 경비 상태를 구분할 수 있는가?
- 벽과 캐릭터의 앞뒤 관계가 어색하지 않은가?
- 작은 화면에서도 주요 정보가 겹치지 않는가?
- CCTV 경고와 출구 봉쇄 경고를 서로 구분할 수 있는가?
- 미탐색, 탐색 기억, 현재 시야의 세 밝기 단계를 구분할 수 있는가?
