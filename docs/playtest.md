# 플레이테스트

이 문서는 게임의 재미와 난이도를 확인하기 위한 질문, 기록 데이터, 기능별 확인 목록을 관리한다.

## 핵심 검증 질문

1. 경비원이 보이지 않을 때도 긴장되는가?
2. 발소리만으로 경비원의 위치를 추측하는 것이 재미있는가?
3. 보물을 획득한 뒤 출구로 돌아가는 과정이 긴장되는가?
4. 첫 보물에서 탈출할지 추가 보물을 노릴지 고민하게 되는가?
5. 밝은 길과 어두운 길이 서로 다른 장단점을 가지는가?

## 자동 저장 위치

최근 12회의 플레이 결과를 브라우저 로컬 스토리지에 저장한다.

```text
shadow-heist-playtests
```

로컬 스토리지는 현재 브라우저 안에만 있는 저장 공간이다. 기록을 외부 서버로 전송하지 않는다.

F2 테스트 패널에서 최근 5개 기록을 바로 확인하고 전체 기록을 JSON 파일로 내려받을 수 있다. 자세한 사용법은 [플레이테스트 도구와 밸런스](playtest-tools.md)에서 설명한다.

## 자동 저장 항목

### 결과

- 탈출 성공 또는 체포
- 플레이 시간
- 확보한 보물과 보물 수
- 원점수와 최종 점수
- 도달한 경계 단계
- 한 판에서 도달한 최대 맵 탐색률

### 경비

- 발각 횟수
- 최고 감지율
- 추격 시간
- 아슬아슬하게 발각을 피한 횟수
- 경비 상태가 바뀐 시간과 플레이어 위치
- 무전 보고 횟수
- 무전을 받고 조사를 시작한 횟수
- 알파와 브라보의 개별 상태 변화

### 플레이어 소음

- 전체 플레이어 발걸음 수
- 경비가 들은 발걸음 수
- 발소리로 경비 조사를 유발한 횟수
- 일반 걷기 시간
- Shift 조심 걷기 시간
- C 웅크리기 이동 시간

### 긴장감 반응

- 첫 경비 발소리를 들은 시간
- 들은 경비 발소리 신호 수
- 발소리를 들은 뒤 멈춰 판단한 횟수
- 발소리를 들은 뒤 반대 방향으로 전환한 횟수
- 첫 탐지가 시작된 시간
- 첫 보물을 획득한 시간
- 위험 신호 없이 갑자기 체포된 것으로 추정되는 횟수
- 첫 4단계 온보딩 완료 여부

이 값들은 발소리가 단순한 장식이 아니라 실제 행동 변화를 만드는지 확인하는 데 사용한다. `멈춤`과 `방향 전환`이 거의 없다면 음량, 좌우감 또는 첫 안내를 다시 조정한다.

### 문과 출입 권한

- 키카드 획득 여부
- 문을 연 횟수와 닫은 횟수
- 잠긴 문을 키카드 없이 사용한 횟수
- 문 조작음으로 경비 조사를 유발한 횟수
- 문·키카드 상호작용 시간과 위치

### 출구 봉쇄

- 새 봉쇄가 시작된 횟수
- 진행 중인 봉쇄가 연장된 횟수
- 봉쇄 중 출구 사용을 시도한 횟수
- 봉쇄 상태에서 생존한 총시간
- 한 번에 적용된 가장 긴 봉쇄 시간
- 게임 종료 시 남은 봉쇄 시간과 봉쇄 중 체포 여부
- 봉쇄 시작·해제·출구 거부 시간과 위치

### 조명

- 최고 노출도
- 밝은 구역 체류 시간
- 어두운 구역 체류 시간
- 사용한 조명 스위치 수
- 스위치 조작 시간과 위치

### 은신

- 은신 진입 횟수
- 은신 상태 총 체류 시간
- 체포되지 않고 나온 횟수
- 경비의 은신처 확인 횟수
- 은신 중 체포 횟수
- 진입·이탈 소리 때문에 조사받은 횟수

### CCTV

- CCTV 시야 진입 횟수
- CCTV 경보 횟수
- 최대 CCTV 감지율
- 제어반 사용 횟수
- 비활성화된 CCTV 시야 통과 횟수
- CCTV 범위 안의 사각지대 체류 시간
- 마지막 CCTV 경보 후 체포까지 걸린 시간

## 기록을 보는 이유

기록은 다음 문제를 찾는 데 사용한다.

- 특정 구역에서 체포가 지나치게 많이 발생하는가?
- 플레이어가 첫 보물만 얻고 항상 바로 탈출하는가?
- 세 번째 보상의 위험에 비해 점수가 충분한가?
- 조명 스위치가 실제로 사용되는가?
- 밝은 길과 어두운 길 중 한쪽만 항상 선택되는가?
- 지나온 길의 형태가 시야 밖에 남지 않아 발소리와 기억에 의존하게 되는가?
- 추격이 너무 짧거나 끝나지 않는가?

## 한 판 테스트 절차

1. 새 게임을 시작한다.
2. 경비가 보이지 않는 상태에서 접근음을 듣는다.
3. 경비 시야에 짧게 들어갔다가 벽 뒤로 숨는다.
4. 의심, 조사, 수색 상태가 이어지는지 확인한다.
5. 경비 시야 밖에서 일반 걷기와 Shift 조심 걷기를 각각 시험한다.
6. 발소리를 들은 경비가 소리 위치를 조사하는지 확인한다.
7. 같은 밝기와 거리에서 서서 이동할 때와 웅크릴 때의 탐지를 비교한다.
8. 한 경비에게 일부러 발각되어 다른 경비가 무전 위치로 오는지 확인한다.
9. 일반 문을 열고 닫아 충돌과 경비 반응을 확인한다.
10. 키카드 없이 보안문을 사용한 뒤 키카드를 찾아 다시 연다.
11. 첫 보물을 획득한다.
12. 경계와 조명이 변하는지 확인한다.
13. 조명 스위치를 한 번 사용한다.
14. 즉시 탈출하거나 추가 보물에 도전한다.
15. 경비가 보지 않을 때와 보고 있을 때 각각 은신한다.
16. CCTV 시야를 짧게 통과한 뒤 감지율이 감소하는지 확인한다.
17. 왕관실 CCTV가 벽 대신 왕관과 보안문 접근로를 훑는지 확인한다.
18. 제어반을 사용하고 비활성화된 카메라를 통과한다.
19. 보물을 가진 상태에서 CCTV 경보를 발생시키고 출구 봉쇄를 확인한다.
20. 봉쇄 중 출구를 사용한 뒤 시간이 끝나면 정상 탈출되는지 확인한다.
21. 결과 화면의 수치와 실제 플레이가 일치하는지 확인한다.
22. 재시작한 뒤 탐색률이 초기화되고 이전 경로가 시야 밖에 남지 않는지 확인한다.
