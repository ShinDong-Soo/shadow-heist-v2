# 강탈과 점수

이 문서는 보물, 선택 탈출, 점수 계산, 전역 경계 단계의 규칙을 설명한다.

## 세 개의 하이스트

게임은 같은 박물관을 사용하지만 위험 요소를 한꺼번에 보여 주지 않는다.

| 순서 | 이름 | 활성 요소 | 성공 조건 |
|---:|---|---|---|
| 1 | `FIRST JOB` | 경비 1명, 청동 유물 1개 | 유물을 훔쳐 서비스 출구로 귀환 |
| 2 | `NIGHT GALLERY` | 경비 2명, CCTV, 보물 2개 | 한 개 이상 훔친 뒤 탈출하거나 둘 다 도전 |
| 3 | `CROWN JEWEL` | 모든 경비·CCTV·보물, 키카드 | 왕관 경보 뒤 동쪽 비상구로 탈출 |

초보 개발자 관점에서 보면 각 하이스트는 별도의 맵 파일이 아니다. `HEISTS` 설정이 이번 판에 활성화할 보물, 보조 경비, CCTV와 왕관 탈출 규칙을 정한다. 따라서 맵을 세 번 복사하지 않고도 난이도를 단계적으로 올릴 수 있다.

## 핵심 선택

두 번째와 세 번째 하이스트에서 보물을 하나 얻은 뒤 플레이어는 두 가지 중 하나를 선택한다.

- 지금 출구로 돌아가 확보한 점수를 지킨다.
- 더 큰 점수를 위해 다음 보물을 노린다.

보물을 더 훔치면 점수는 커지지만 경비와 비상등도 강해진다.

추가 보물이 남아 있을 때만 첫 보물 획득 직후 약 3.2초 동안 현재 확보 점수, 즉시 탈출, 다음 보물 배수, 체포 시 전액 손실을 상단에 표시한다. 보물이 하나뿐인 `FIRST JOB`에서는 의미 없는 선택 안내를 띄우지 않는다.

## 보물

| 보물 | 기본 점수 | 위치와 역할 |
|---|---:|---|
| 청동 유물 | 1,000 | 시작 구역과 가까운 저위험 보물 |
| 밤의 보석 | 1,800 | 중앙 전시 구역의 중위험 보물 |
| 황금 왕관 | 3,200 | 박물관 깊은 곳의 고위험 보물 |

- 가까이에서 E를 누르면 획득한다.
- 획득한 보물은 화면에서 사라진다.
- 해당 보물의 전시 조명도 꺼진다.
- 경비원은 보물이 사라진 위치를 조사한다.

## 탈출

- 보물을 하나 이상 획득해야 출구를 사용할 수 있다.
- 보물 하나만 가지고 탈출해도 성공이다.
- 보물을 얻지 않은 상태에서는 출구를 사용할 수 없다.
- 경비원과 접촉해 체포되면 해당 판의 점수를 모두 잃는다.

### 왕관 전용 탈출

`CROWN JEWEL`에서 황금 왕관을 훔치면 일반 규칙이 바뀐다.

1. 서비스 출구가 즉시 영구 봉쇄된다.
2. 경계가 Level 3으로 올라가고 두 경비가 추격을 시작한다.
3. 박물관 동쪽의 `EMERGENCY EXIT`가 새 목표가 된다.

이 구간은 마지막 보물을 얻은 뒤 되돌아가는 과정이 반복처럼 느껴지지 않게 만든 피날레다. 화면 목표 문구와 출구 표지판이 함께 바뀌므로 플레이어가 새 동선을 알아볼 수 있다.

## 출구 봉쇄

보물을 가진 플레이어에게 보안 경보가 발생하면 출구가 일정 시간 잠긴다.

| 발생 조건 | 봉쇄 시간 |
|---|---:|
| 보물을 가진 상태에서 CCTV 경보 발생 | 7초 + 현재 경계 단계마다 2초 |
| 두 번째 하이스트의 마지막 보물 획득 | 11초 + 현재 경계 단계마다 1.5초 |

- 봉쇄 시간은 화면 상단과 출구에 실시간으로 표시된다.
- 봉쇄 중에는 출구까지 도착해도 탈출할 수 없다.
- 다시 경보가 발생하면 기존 시간과 새 시간 중 더 긴 값을 사용한다.
- 시간이 0초가 되면 출구가 자동으로 다시 열린다.
- 첫 번째 하이스트와 각 판의 첫 보물 획득만으로는 봉쇄되지 않는다.
- 세 번째 하이스트의 왕관은 시간제 봉쇄 대신 왕관 전용 탈출 규칙을 사용한다.
- 보물을 가지기 전 발생한 CCTV 경보도 출구를 봉쇄하지 않는다.

봉쇄는 플레이어를 영구적으로 가두는 장치가 아니다. 숨기, 문 닫기, 어두운 이동로를 이용해 정해진 시간만 버티게 만드는 귀환 구간용 압박이다.

## 점수 계산

점수는 다음 순서로 계산한다.

1. 획득한 보물의 기본 점수를 더한다.
2. 여러 보물을 획득했다면 연속 획득 배수를 적용한다.
3. 탈출에 성공하면 플레이 시간에 따른 보너스를 추가한다.
4. 발각 횟수에 따른 미발각 보너스를 추가한다.

현재 배수는 다음과 같다.

| 보물 수 | 확보 점수 배수 |
|---:|---:|
| 0 | 0배 |
| 1 | 1배 |
| 2 | 1.15배 |
| 3 | 1.35배 |

체포되면 계산 중인 확보 점수와 관계없이 최종 점수는 0점이다.

## 전역 경계 단계

| 단계 | 조건 | 주요 변화 |
|---|---|---|
| Level 0 | 보물 도난과 CCTV 경보 전 | 기본 순찰과 탐지 성능 |
| Level 1 | 보물 1개 도난 또는 첫 CCTV 경보 | 경비 이동, 시야, 수색 능력 증가 |
| Level 2 | 추가 보물 도난 또는 CCTV 경보 | 경비 추가 강화와 순찰 방향 역전 |
| Level 3 | 반복 경보 또는 최고 위험 상태 | 가장 강한 탐지와 긴 출구 봉쇄 |

각 보물 획득 시 현재 보물 수보다 경계 단계가 낮다면 즉시 올라간다. CCTV 경보도 현재 단계와 보물 수를 기준으로 경계를 최소 한 단계 상승시킬 수 있다. 경계 단계는 한 판이 끝날 때까지 내려가지 않는다.

경비 능력에 적용되는 내용은 [경비원 AI](guard-ai.md#경계-단계에-따른-강화), 비상등 변화는 [맵, 시야, 조명](map-vision-lighting.md#보물-및-경계-단계-연동)에서 설명한다.
CCTV 경보 규칙은 [CCTV](cctv.md#cctv-경보)에서 관리한다.

## 현재 게임 루프

```text
FIRST JOB에서 기본 규칙 학습
→ 결과 화면에서 점수 확인 후 다음 하이스트
→ NIGHT GALLERY에서 조기 탈출 또는 추가 보물 선택
→ CROWN JEWEL에서 모든 보물과 왕관 도전
→ 왕관 경보 후 동쪽 비상구로 도주
→ 결과와 하이스트별 최고 점수 확인
```

## 직접 확인할 것

- 보물 하나만 얻어도 출구를 사용할 수 있는가?
- 획득한 보물의 점수가 HUD에 정확히 반영되는가?
- 추가 보물 획득 시 배수와 경계 단계가 올라가는가?
- 체포되면 최종 점수가 0점인가?
- 조기 탈출과 고득점 도전이 모두 의미 있는 선택인가?
- 첫 보물 연출을 본 뒤 즉시 탈출과 추가 강탈 중 무엇을 할지 고민하게 되는가?
- CCTV 경보 후 봉쇄가 귀환을 긴장시키되 지나치게 오래 느껴지지 않는가?
- 마지막 보물의 긴 봉쇄를 버틸 수 있는 안전한 선택지가 있는가?
- 첫 하이스트에서 보조 경비와 CCTV가 보이거나 작동하지 않는가?
- 왕관 획득 뒤 서비스 출구가 닫히고 동쪽 비상구가 활성화되는가?
- 성공 결과에서 다음 하이스트 버튼이 보이고 마지막 하이스트에서는 숨겨지는가?
