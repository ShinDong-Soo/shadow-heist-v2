# 강탈과 점수

이 문서는 보물, 선택 탈출, 점수 계산, 전역 경계 단계의 규칙을 설명한다.

## 핵심 선택

보물을 하나 얻은 뒤 플레이어는 두 가지 중 하나를 선택한다.

- 지금 출구로 돌아가 확보한 점수를 지킨다.
- 더 큰 점수를 위해 다음 보물을 노린다.

보물을 더 훔치면 점수는 커지지만 경비와 비상등도 강해진다.

## 보물

| 보물 | 기본 점수 | 위치와 역할 |
|---|---:|---|
| 청동 유물 | 1,000 | 시작 구역과 가까운 저위험 보물 |
| 밤의 보석 | 1,800 | 중앙 전시 구역의 중위험 보물 |
| 황금 왕관 | 3,200 | 박물관 깊은 곳의 고위험 보물 |

- 가까이에서 E를 누르면 획득한다.
- 획득한 보물은 화면에서 사라진다.
- 해당 보물의 전시 조명도 꺼진다.
- 경비원은 보물이 사라진 위치를 조사한다.

## 탈출

- 보물을 하나 이상 획득해야 출구를 사용할 수 있다.
- 보물 하나만 가지고 탈출해도 성공이다.
- 보물을 얻지 않은 상태에서는 출구를 사용할 수 없다.
- 경비원과 접촉해 체포되면 해당 판의 점수를 모두 잃는다.

## 점수 계산

점수는 다음 순서로 계산한다.

1. 획득한 보물의 기본 점수를 더한다.
2. 여러 보물을 획득했다면 연속 획득 배수를 적용한다.
3. 탈출에 성공하면 플레이 시간에 따른 보너스를 추가한다.
4. 발각 횟수에 따른 미발각 보너스를 추가한다.

현재 배수는 다음과 같다.

| 보물 수 | 확보 점수 배수 |
|---:|---:|
| 0 | 0배 |
| 1 | 1배 |
| 2 | 1.15배 |
| 3 | 1.35배 |

체포되면 계산 중인 확보 점수와 관계없이 최종 점수는 0점이다.

## 전역 경계 단계

| 단계 | 조건 | 주요 변화 |
|---|---|---|
| Level 0 | 보물 도난 전 | 기본 순찰과 탐지 성능 |
| Level 1 | 보물 1개 도난 | 경비 이동, 시야, 수색 능력 증가 |
| Level 2 | 보물 2개 도난 | 경비 추가 강화와 순찰 방향 역전 |
| Level 3 | 보물 3개 도난 | 가장 강한 탐지와 출구 방향 압박 |

각 보물 획득 시 경계 단계는 즉시 한 단계 올라간다.

경비 능력에 적용되는 내용은 [경비원 AI](guard-ai.md#경계-단계에-따른-강화), 비상등 변화는 [맵, 시야, 조명](map-vision-lighting.md#보물-및-경계-단계-연동)에서 설명한다.

## 현재 게임 루프

```text
박물관 진입
→ 첫 보물 탐색
→ 보물 획득 및 경계 상승
→ 즉시 탈출 또는 추가 보물 도전
→ 출구 도착 또는 체포
→ 최종 점수 확인
```

## 직접 확인할 것

- 보물 하나만 얻어도 출구를 사용할 수 있는가?
- 획득한 보물의 점수가 HUD에 정확히 반영되는가?
- 추가 보물 획득 시 배수와 경계 단계가 올라가는가?
- 체포되면 최종 점수가 0점인가?
- 조기 탈출과 고득점 도전이 모두 의미 있는 선택인가?
