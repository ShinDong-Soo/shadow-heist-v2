## 주요 용어

| 용어 | 쉬운 설명 |
|---|---|
| 프로토타입 | 완성품 전에 기능과 재미를 시험하는 버전 |
| 게임 루프 | 한 판에서 반복되는 플레이 흐름 |
| HUD | 화면 위에 표시되는 목표, 점수, 상태 정보 |
| LOS | 두 대상 사이를 벽이 막고 있는지 확인하는 계산 |
| AI 상태 | 경비원이 현재 어떤 행동 중인지 나타내는 값 |
| A* | 벽을 피해 목적지까지 가는 경로를 찾는 방법 |
| Fake 2.5D | 2D 도형에 옆면과 그림자를 더해 높이가 있어 보이게 하는 방식 |
| 로컬 스토리지 | 서버 없이 현재 브라우저에 데이터를 저장하는 공간 |
| 빌드 | 코드를 브라우저에서 실행 가능한 결과물로 만드는 과정 |

## 현재 게임 흐름

```text
박물관 진입
→ 빛과 소리로 경비 위치 추측
→ 보물 획득
→ 경계 단계 상승
→ 지금 탈출하거나 추가 보물에 도전
→ 출구 도착 또는 체포
→ 결과와 플레이테스트 기록 확인
```

## 문서 관리 규칙

1. 새 기능은 가장 관련 있는 문서 한 곳에만 상세히 기록한다.
2. 다른 분야에서도 알아야 하는 규칙은 설명을 복사하지 않고 링크를 건다.
3. 기존 기능이 바뀌면 이전 설명을 남기지 않고 현재 동작으로 수정한다.
4. [변경 이력](changelog.md)에는 상세 설명 대신 변경 분야만 한 줄로 추가한다.
5. 어려운 용어에는 바로 옆이나 아래에 쉬운 설명을 붙인다.
