# 플레이어와 조작

이 문서는 플레이어 이동과 키 입력, 상호작용 규칙을 설명한다.

## 조작법

| 입력 | 동작 |
|---|---|
| WASD / 방향키 | 기본 저소음 이동 |
| Shift | 누르는 동안 달리기·큰 소음 발생 |
| C | 누르고 있는 동안 웅크리기 |
| E | 보물·키카드 획득, 문 열기·닫기, 숨기·나오기, CCTV 제어반, 출구 탈출, 조명 스위치 조작 |
| F2 | 개발자 플레이테스트 패널 열기·닫기 |

## 이동

- 플레이어는 입력한 방향으로 이동하고 해당 방향을 바라본다.
- 대각선 입력은 속도를 보정해 가로·세로 이동보다 빨라지지 않게 한다.
- 키를 놓으면 즉시 멈추지 않고 매우 짧게 감속한다.
- 기본 이동은 잠입에 적합한 저소음 걷기다.
- Shift를 누르면 빠르게 달리지만 발소리가 훨씬 멀리 퍼진다.
- C를 누르면 가장 느린 웅크리기 이동을 사용한다.
- 실제로 이동한 거리에 맞춰 다리 애니메이션의 빠르기가 변한다.
- 벽에 막혀 위치가 바뀌지 않으면 걷기 애니메이션과 발소리도 멈춘다.

걷기 애니메이션은 충돌 처리가 끝난 뒤의 실제 위치 변화를 사용한다. 입력만 있고 움직이지 못한 경우에는 재생하지 않으며, 방향이 바뀌면 첫 착지 자세에서 새 주기를 시작한다. 이 변경은 그림 재생만 보정하며 이동 속도와 충돌 판정은 바꾸지 않는다. 자세한 프레임 거리와 피벗 규칙은 [캐릭터 에셋](characters.md#재생-속도)에서 관리한다.

별도의 `조심히 걷기` 키는 제거했다. 평소에는 안전하게 걷고, 급할 때만 Shift로 소음 위험을 감수하는 두 가지 선택에 집중하기 위해서다. 보물을 많이 들수록 어떤 자세에서도 발소리 범위가 조금 넓어진다.

## 웅크리기

웅크리기는 속도를 더 포기하고 소리와 시각 노출을 함께 줄이는 자세다.

| 상태 | 이동 속도 | 기본 소음 범위 | 시각 탐지 배율 |
|---|---:|---:|---:|
| 기본 저소음 걷기 | 150 | 115 | 100% |
| Shift 달리기 | 215 | 390 | 100% |
| C 웅크리기 | 88 | 65 | 70% |

- C와 Shift를 동시에 누르면 웅크리기를 우선한다. 따라서 웅크린 채 달릴 수는 없다.
- 웅크리면 플레이어 제한 시야도 조금 좁아진다.
- 웅크려도 밝은 곳이나 경비 바로 앞에서는 발견될 수 있다.
- 웅크리기는 은신처처럼 플레이어를 완전히 숨기지 않는다.
- 보물을 들면 웅크린 발소리도 조금 커진다.

정확한 소음 거리와 벽의 영향은 [사운드](audio.md#플레이어-발소리와-소음)에서 설명한다.

## 충돌

플레이어의 발은 원으로 계산하고, 벽과 문에는 몸통과 머리 위치의 작은 충돌 원도 함께 검사한다. 이동하려는 위치에서 세 지점 중 하나라도 건축물과 겹치면 해당 방향의 이동을 취소한다. 따라서 발만 벽 밖에 있고 캐릭터 이미지의 상체는 벽 안으로 들어가는 현상을 줄인다.

열린 문 통로 안에서는 예외적으로 발 충돌 원만 사용한다. 상체와 머리 보조 원은 발보다 위쪽에 있으므로 좁은 문을 지날 때 문틀 양옆 벽을 동시에 잡아 정상적인 통로를 막을 수 있기 때문이다. 닫힌 문과 일반 벽에서는 기존의 몸 전체 충돌을 그대로 사용하므로 캐릭터가 벽 속으로 들어가지는 않는다.

벽뿐 아니라 커튼·보관함·기록 선반 같은 은신 설비, 조명 제어 단말, CCTV 제어대도 작은 물리 장애물로 계산한다. 따라서 캐릭터가 장치 위를 걸어가거나 몸이 장치와 완전히 포개지지 않는다.

가로와 세로 이동을 따로 검사하기 때문에 벽을 비스듬히 향해 이동하면 벽면을 따라 미끄러지듯 움직일 수 있다.

경비원 길찾기도 같은 몸 전체 충돌을 사용한다. 화면에서 보이는 캐릭터 크기와 실제 이동 가능 공간이 서로 다르지 않게 하기 위한 처리다.

맵 구조와 충돌 대상은 [맵, 시야, 조명](map-vision-lighting.md)에서 설명한다.

## 상호작용

플레이어가 대상 가까이에 있을 때 E를 누르면 상호작용한다.

우선순위는 다음과 같다.

1. 획득하지 않은 보물
2. 획득하지 않은 키카드
3. 은신처 진입 또는 이탈
4. 아직 사용하지 않은 CCTV 제어반
5. 조명 스위치
6. 문 열기 또는 닫기
7. 보물을 가진 상태에서 출구

은신의 전체 규칙은 [숨기 시스템](hiding.md)에서 관리한다.
CCTV 제어반 규칙은 [CCTV](cctv.md#제어반)에서 관리한다.
문과 키카드 규칙은 [문과 출입 권한](doors-and-access.md)에서 관리한다.
F2 패널 사용법은 [플레이테스트 도구와 밸런스](playtest-tools.md)에서 관리한다.

가까이에 상호작용 대상이 있으면 화면 아래쪽에 대상 이름과 E 안내가 표시된다.

## 캐릭터 표시

- 플레이어는 청록색 계열로 표시한다.
- 이동 방향에 맞춰 몸과 시선이 회전한다.
- 이동 속도에 맞춰 다리가 움직인다.
- 보물을 하나 이상 획득하면 가방이 표시된다.

자세한 렌더링 방식은 [UI와 그래픽](ui-and-visuals.md)에서 설명한다.

## 직접 확인할 것

- 대각선 이동이 더 빠르지 않은가?
- Shift 달리기가 기본 걷기보다 확실히 빠른가?
- Shift 달리기의 소음 파동이 기본 걷기보다 훨씬 넓은가?
- 경비 가까이에서는 달리기가 실제 조사를 유발하는가?
- C 웅크리기가 기본 걷기보다 느리지만 더 안전하게 느껴지는가?
- 웅크린 상태에서도 밝은 장소와 가까운 경비는 충분히 위험한가?
- 벽 모서리에서 캐릭터가 끼지 않는가?
- 은신 설비와 제어 장치 위로 걸어가지 않는가?
- 벽을 계속 밀 때 제자리 걷기나 발소리가 발생하지 않는가?
- 보물, 스위치, 출구의 E 안내가 정확히 바뀌는가?
- 문과 키카드의 E 안내가 현재 상태에 맞게 바뀌는가?
- 열린 문 중앙으로 걸으면 끼거나 한쪽으로 밀려나지 않고 통과하는가?
