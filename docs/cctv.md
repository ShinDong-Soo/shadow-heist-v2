# CCTV

이 문서는 CCTV의 회전 감시, 플레이어 탐지, 경비 연동, 제어반 규칙을 설명한다.

## 개발 목표

CCTV의 반복되는 회전 방향을 읽고 사각지대를 통과하게 만든다. CCTV 발각은 즉시 실패가 아니라 경비에게 플레이어 위치가 전달되는 위험으로 작동한다.

## 배치

현재 고정된 CCTV 3대가 있다.

| CCTV | 감시 구역 |
|---|---|
| 중앙 전시실 CCTV | 중앙 전시실과 연결 통로 |
| 왕관실 CCTV | 왕관실 우측 상단에서 왕관과 보안문 방향을 회전 감시 |
| 출구 회랑 CCTV | 출구로 돌아오는 회랑 |

각 카메라의 위치와 기본 회전 범위는 [src/cctv.ts](../src/cctv.ts)에 저장한다.

왕관실 CCTV는 벽 바로 앞에서 벽 쪽을 바라보던 이전 배치를 수정했다. 현재는 우측 상단 모서리에서 방 안쪽을 향하며, 회전 범위 전체가 왕관실 내부와 보안문 접근로를 통과한다.

세 CCTV 제어반은 독립형 바닥 키오스크가 아니라 가까운 세로 벽에 브래킷으로 고정한다. 장치가 차지하는 충돌 영역도 본체 크기인 20 × 28px만 사용한다. 따라서 제어반은 실제 장애물이지만 통로 한가운데에서 길을 막지는 않는다.

## 배치 검사

게임을 불러올 때 각 CCTV의 회전 범위에 25개의 시험 광선을 발사한다.

- 평균 시야 길이가 설정 거리의 35%보다 짧으면 경고한다.
- 시험 광선 절반 이상이 90픽셀 안에서 벽에 막혀도 경고한다.
- 문제가 발견되면 브라우저 개발자 콘솔에 카메라 이름과 측정값을 표시한다.

이 검사는 게임 플레이를 중단하지 않는다. 새 CCTV를 추가하거나 벽을 옮겼을 때 잘못된 방향을 빠르게 발견하기 위한 개발 보조 기능이다.

## 상태

```text
SCAN
→ DETECTING
→ ALERT
→ COOLDOWN
→ SCAN

제어반 사용
→ DISABLED
→ SCAN
```

| 상태 | 행동 |
|---|---|
| SCAN | 정해진 두 각도 사이를 왕복 회전한다. |
| DETECTING | 플레이어를 보고 감지 게이지를 올린다. |
| ALERT | 경비에게 마지막 영상 위치를 전달한다. |
| COOLDOWN | 경보 후 잠시 감지를 중지한다. |
| DISABLED | 제어반 때문에 일정 시간 작동하지 않는다. |

## 탐지 조건

플레이어가 감지되려면 다음 조건이 모두 필요하다.

1. CCTV 시야 원뿔 안에 있어야 한다.
2. 플레이어와 CCTV 사이에 벽이 없어야 한다.
3. 은신처 밖에 있어야 한다.
4. 일정 시간 이상 계속 보여야 한다.

플레이어가 밝은 곳에 있으면 탐지 속도와 유효 거리가 증가한다. 어두운 곳에서는 감소한다.

플레이어가 C로 웅크리면 탐지 속도와 유효 거리가 70%로 감소한다. 완전히 보이지 않는 상태는 아니므로 가까운 거리나 밝은 조명 아래에서는 계속 감지된다.

LOS와 노출도 계산은 [맵, 시야, 조명](map-vision-lighting.md)에서 관리한다.

## CCTV 경보

감지 게이지가 가득 차면 다음 일이 발생한다.

- 전역 경계 단계가 최소 한 단계 상승한다.
- 비상등과 경보 분위기가 활성화된다.
- 경비원에게 현재 플레이어 위치가 전달된다.
- 경비가 추격 중이면 최신 추격 위치로 사용한다.
- 추격 중이 아니면 해당 위치를 조사한다.
- CCTV는 잠시 경보 상태를 표시한 뒤 재사용 대기 상태가 된다.

CCTV만으로 플레이어를 즉시 체포하지는 않는다.

## 경계 단계 연동

- 경계 단계가 높을수록 회전 속도가 빨라진다.
- 시야 거리가 증가한다.
- 감지 속도가 증가한다.
- 경보 후 재사용 대기시간이 짧아진다.
- Level 3에서는 경보 후 일부 카메라의 회전 방향이 바뀐다.

## 제어반

각 CCTV에는 대응하는 제어반이 한 개씩 있다.

- 가까이에서 E를 누르면 연결된 CCTV가 일시적으로 꺼진다.
- 각 제어반은 한 판에 한 번만 사용할 수 있다.
- 경계 단계가 높을수록 비활성화 시간이 짧아진다.
- CCTV 본체 위에 복구까지 남은 시간이 표시된다.
- 조작음을 가까운 경비가 들으면 제어반 위치를 조사한다.

## 은신 연동

- 은신처 안의 플레이어는 CCTV가 감지하지 못한다.
- CCTV가 플레이어의 은신처 진입 자체를 별도로 기억하지는 않는다.
- 은신처 밖으로 나올 때 CCTV 시야에 있으면 새로 감지를 시작한다.

은신의 전체 규칙은 [숨기 시스템](hiding.md)에서 관리한다.

## 화면과 사운드

- 평상시 시야: 청백색
- 감지 중 시야: 노란색
- 경보 시야: 붉은색
- 비활성화: 회색 본체와 `OFF` 시간
- 화면 상단: CCTV 감지 진행률
- 회전 중: 작은 모터음
- 경보 발생: 짧은 전자 경고음
- 제어반 사용: 전자 스위치음

상세 소리는 [사운드](audio.md), HUD는 [UI와 그래픽](ui-and-visuals.md)에서 관리한다.

## 직접 확인할 것

- 세 CCTV가 정해진 범위에서 왕복 회전하는가?
- 벽과 전시대가 CCTV 시야를 막는가?
- 시야에서 빠르게 벗어나면 감지 게이지가 감소하는가?
- 밝은 장소에서 더 빠르게 감지되는가?
- 같은 위치에서 웅크리면 감지 속도와 거리가 줄어드는가?
- CCTV 경보가 경비 조사로 이어지는가?
- 제어반으로 끈 CCTV가 시간이 지나면 복구되는가?
- 은신처 안에서는 CCTV에 감지되지 않는가?
- 왕관실 CCTV가 벽이 아니라 왕관과 보안문 접근로를 훑는가?
- 카메라를 새로 배치했을 때 콘솔에 시야 차단 경고가 발생하지 않는가?
