# 경비원 AI

이 문서는 두 경비원의 판단 상태, 시야, 조사, 추격, 길찾기와 정보 공유 규칙을 설명한다.

## 경비 구성

| 경비 | 시작 구역 | 기본 역할 |
|---|---|---|
| 알파 | 서쪽·중앙 구역 | 기존 순찰로를 따라 전시실과 중앙 통로를 감시한다. |
| 브라보 | 기록 보관소·동쪽 구역 | 키카드 주변과 동쪽 이동로를 순찰한다. |

두 경비는 서로 다른 위치와 순찰 경로, 감지 수치, 마지막 목격 위치를 가진다. 따라서 한 경비의 시야를 피했더라도 다른 방향에서 브라보와 마주칠 수 있다.

## 상태 흐름

```text
PATROL
→ SUSPICIOUS
→ INVESTIGATE
→ CHASE
→ SEARCH
→ PATROL
```

`HIDE_CHECK`는 플레이어가 들어간 것으로 의심되는 은신처를 직접 확인할 때 사용한다.

브라보는 현재 `HIDE_CHECK`를 직접 수행하지 않는다. 브라보가 은신 장면을 목격하면 알파에게 위치를 공유하고 알파가 은신처를 확인한다.

| 상태 | 쉬운 설명 | 행동 |
|---|---|---|
| PATROL | 순찰 | 지정된 경로를 따라 걷는다. |
| SUSPICIOUS | 의심 | 플레이어를 잠깐 보면 멈춰서 방향을 확인한다. |
| INVESTIGATE | 조사 | 마지막 목격 지점이나 이상 현상이 발생한 곳으로 이동한다. |
| CHASE | 추격 | 플레이어를 확실히 발견하면 빠르게 쫓는다. |
| SEARCH | 수색 | 플레이어를 놓친 장소 주변을 여러 지점으로 이동하며 찾는다. |
| HIDE_CHECK | 은신처 확인 | 의심되는 은신처 앞으로 이동해 내부를 확인한다. |

## 기본 탐지

플레이어가 발각되려면 다음 조건을 만족해야 한다.

1. 경비원 앞쪽의 시야 원뿔 안에 있어야 한다.
2. 경비원과 플레이어 사이에 벽이 없어야 한다.
3. 일정 시간 이상 계속 보여야 한다.

짧게만 보였다면 즉시 추격하지 않고 의심 상태로 들어간다. 충분히 오래 보이면 감지 게이지가 가득 차고 추격을 시작한다.

## 밝기와 탐지

플레이어의 현재 노출도를 경비 탐지 계산에 사용한다.

- 밝은 장소에서는 탐지 거리와 감지 속도가 증가한다.
- 어두운 장소에서는 탐지 거리와 감지 속도가 감소한다.
- 추격 상태에서는 평상시보다 시야 각도와 기본 거리가 넓어진다.
- 플레이어가 웅크리면 최종 탐지 거리와 감지 속도가 70%로 감소한다.

웅크리기는 밝기 계산을 없애지 않는다. 밝은 조명 아래에서 경비 가까이 웅크리면 여전히 빠르게 발견될 수 있다. 입력과 이동 수치는 [플레이어와 조작](player-and-controls.md#웅크리기)에서 관리한다.

노출도 계산 자체는 [맵, 시야, 조명](map-vision-lighting.md#플레이어-노출도)에서 관리한다.

## 조사

경비원은 다음 위치를 조사할 수 있다.

- 플레이어를 마지막으로 본 위치
- 보물이 사라진 전시 위치
- 플레이어가 들어가는 모습을 본 은신처
- CCTV가 마지막으로 감지한 플레이어 위치
- 경비가 마지막으로 들은 플레이어 발소리 위치
- 플레이어가 조작한 문 위치

조사 위치에 도착했지만 플레이어를 찾지 못하면 수색 상태로 전환한다.

첫 번째 하이스트에서는 알파 경비만 활성화된다. 두 번째 하이스트부터 브라보 경비가 등장하고, 두 경비가 무전으로 마지막 목격 위치를 공유한다. 플레이어가 한 경비의 시야와 발소리를 먼저 익힌 뒤 협동 수색을 상대하게 하기 위한 단계 구성이다.

발소리는 시야 감지 게이지를 직접 가득 채우지 않는다. 경비는 소리만 들었을 때 곧바로 추격하는 대신 소리가 난 위치를 조사한다. 소음 거리와 벽 차폐 수치는 [사운드](audio.md#플레이어-발소리와-소음)에서 관리한다.

은신처를 목격했거나 높은 경계 단계에서 주변 은신처를 의심하면 `HIDE_CHECK` 상태로 전환한다. 세부 규칙은 [숨기 시스템](hiding.md)에서 관리한다.

## 추격과 수색

- 추격 중 플레이어가 보이면 마지막 목격 위치를 계속 갱신한다.
- 벽 뒤로 사라지면 마지막으로 본 위치까지 쫓아간다.
- 일정 시간 동안 다시 발견하지 못하면 조사 상태로 전환한다.
- 조사 위치에 도착한 뒤 주변 여러 지점을 약 7.5초 이상 수색한다.
- 경계 단계가 높으면 수색 시간과 방문 지점 수가 증가한다.
- 수색에 실패하면 다시 순찰한다.

## 무전 정보 공유

다음 사건이 발생하면 짧은 무전음과 함께 위치가 공유된다.

- 알파 또는 브라보가 플레이어를 확실히 발견해 추격을 시작함
- CCTV 탐지가 완료됨
- 보물이 사라짐
- 경비가 큰 문 닫기 소리를 들음
- 브라보가 플레이어의 은신 장면을 목격함

보고를 받은 경비는 바로 플레이어를 본 것으로 처리되지 않는다. 공유된 위치로 `INVESTIGATE` 상태로 이동한 뒤 직접 시야로 확인해야 추격한다. 무전은 1.2초의 짧은 재사용 대기시간이 있어 같은 순간의 보고가 반복 재생되지 않는다.

## A* 길찾기

A*는 벽을 피해 목적지까지 가는 경로를 찾는 방법이다.

1. 박물관을 40픽셀 크기의 칸으로 나눈다.
2. 벽과 전시대가 있는 칸을 이동 불가로 표시한다.
3. 현재 칸에서 목적지 칸까지 이어지는 통로를 찾는다.
4. 찾은 칸을 차례로 이동 지점으로 사용한다.

목적지까지 직선으로 갈 수 있으면 복잡한 길찾기를 생략한다. 추격처럼 목적지가 계속 움직이는 상황에서는 짧은 간격으로 경로를 다시 계산한다.

## 경계 단계에 따른 강화

전역 경계 단계가 높을수록 다음 수치가 증가한다.

- 순찰 이동 속도
- 조사 이동 속도
- 추격 이동 속도
- 수색 이동 속도와 시간
- 시야 거리
- 감지 속도

Level 2부터 순찰 방향이 역전된다. Level 3에서는 보물 조사 후 출구에 가까운 순찰 지점을 우선한다.

보물 도난과 CCTV 경보가 경계 단계에 영향을 준다. 전체 조건은 [강탈과 점수](heist-and-scoring.md#전역-경계-단계)에서 설명한다.

## 화면 표현

- 순찰: 황금색
- 의심과 조사: 주황색 및 `?`
- 수색: 주황색 및 `…`
- 추격: 붉은색과 화면 가장자리 경고

손전등과 캐릭터 표현은 [UI와 그래픽](ui-and-visuals.md#경비원-표현)에서 관리한다.

## 직접 확인할 것

- 잠깐 보인 뒤 숨으면 조사 상태로 들어가는가?
- 추격 중 벽 뒤로 숨으면 마지막 목격 위치까지 오는가?
- 수색이 끝난 뒤 다시 순찰하는가?
- 경비가 벽을 뚫거나 모서리에 계속 걸리지 않는가?
- 경계 레벨이 높을수록 실제로 더 위협적인가?
- 경비가 플레이어를 보지 못해도 큰 발소리를 따라오는가?
- 가까운 문 조작음을 듣고 해당 문으로 조사하러 오는가?
- 한 경비에게 발각되면 다른 경비도 무전 위치로 이동하는가?
- 보고를 받은 경비가 곧바로 추격하지 않고 먼저 조사하는가?
- 같은 위치에서 서 있을 때와 웅크릴 때 탐지 차이가 느껴지는가?
