# 경비원 AI

이 문서는 경비원의 판단 상태, 시야, 조사, 추격, 길찾기 규칙을 설명한다.

## 상태 흐름

```text
PATROL
→ SUSPICIOUS
→ INVESTIGATE
→ CHASE
→ SEARCH
→ PATROL
```

`HIDE_CHECK`는 플레이어가 들어간 것으로 의심되는 은신처를 직접 확인할 때 사용한다.

| 상태 | 쉬운 설명 | 행동 |
|---|---|---|
| PATROL | 순찰 | 지정된 경로를 따라 걷는다. |
| SUSPICIOUS | 의심 | 플레이어를 잠깐 보면 멈춰서 방향을 확인한다. |
| INVESTIGATE | 조사 | 마지막 목격 지점이나 이상 현상이 발생한 곳으로 이동한다. |
| CHASE | 추격 | 플레이어를 확실히 발견하면 빠르게 쫓는다. |
| SEARCH | 수색 | 플레이어를 놓친 장소 주변을 여러 지점으로 이동하며 찾는다. |
| HIDE_CHECK | 은신처 확인 | 의심되는 은신처 앞으로 이동해 내부를 확인한다. |

## 기본 탐지

플레이어가 발각되려면 다음 조건을 만족해야 한다.

1. 경비원 앞쪽의 시야 원뿔 안에 있어야 한다.
2. 경비원과 플레이어 사이에 벽이 없어야 한다.
3. 일정 시간 이상 계속 보여야 한다.

짧게만 보였다면 즉시 추격하지 않고 의심 상태로 들어간다. 충분히 오래 보이면 감지 게이지가 가득 차고 추격을 시작한다.

## 밝기와 탐지

플레이어의 현재 노출도를 경비 탐지 계산에 사용한다.

- 밝은 장소에서는 탐지 거리와 감지 속도가 증가한다.
- 어두운 장소에서는 탐지 거리와 감지 속도가 감소한다.
- 추격 상태에서는 평상시보다 시야 각도와 기본 거리가 넓어진다.

노출도 계산 자체는 [맵, 시야, 조명](map-vision-lighting.md#플레이어-노출도)에서 관리한다.

## 조사

경비원은 다음 위치를 조사할 수 있다.

- 플레이어를 마지막으로 본 위치
- 보물이 사라진 전시 위치
- 플레이어가 조작한 조명 스위치 위치
- 플레이어가 들어가는 모습을 본 은신처

조사 위치에 도착했지만 플레이어를 찾지 못하면 수색 상태로 전환한다.

은신처를 목격했거나 높은 경계 단계에서 주변 은신처를 의심하면 `HIDE_CHECK` 상태로 전환한다. 세부 규칙은 [숨기 시스템](hiding.md)에서 관리한다.

## 추격과 수색

- 추격 중 플레이어가 보이면 마지막 목격 위치를 계속 갱신한다.
- 벽 뒤로 사라지면 마지막으로 본 위치까지 쫓아간다.
- 일정 시간 동안 다시 발견하지 못하면 조사 상태로 전환한다.
- 조사 위치에 도착한 뒤 주변 여러 지점을 약 7.5초 이상 수색한다.
- 경계 단계가 높으면 수색 시간과 방문 지점 수가 증가한다.
- 수색에 실패하면 다시 순찰한다.

## A* 길찾기

A*는 벽을 피해 목적지까지 가는 경로를 찾는 방법이다.

1. 박물관을 40픽셀 크기의 칸으로 나눈다.
2. 벽과 전시대가 있는 칸을 이동 불가로 표시한다.
3. 현재 칸에서 목적지 칸까지 이어지는 통로를 찾는다.
4. 찾은 칸을 차례로 이동 지점으로 사용한다.

목적지까지 직선으로 갈 수 있으면 복잡한 길찾기를 생략한다. 추격처럼 목적지가 계속 움직이는 상황에서는 짧은 간격으로 경로를 다시 계산한다.

## 경계 단계에 따른 강화

보물을 더 많이 훔칠수록 다음 수치가 증가한다.

- 순찰 이동 속도
- 조사 이동 속도
- 추격 이동 속도
- 수색 이동 속도와 시간
- 시야 거리
- 감지 속도

Level 2부터 순찰 방향이 역전된다. Level 3에서는 보물 조사 후 출구에 가까운 순찰 지점을 우선한다.

경계 단계가 올라가는 조건은 [강탈과 점수](heist-and-scoring.md#전역-경계-단계)에서 설명한다.

## 화면 표현

- 순찰: 황금색
- 의심과 조사: 주황색 및 `?`
- 수색: 주황색 및 `…`
- 추격: 붉은색과 화면 가장자리 경고

손전등과 캐릭터 표현은 [UI와 그래픽](ui-and-visuals.md#경비원-표현)에서 관리한다.

## 직접 확인할 것

- 잠깐 보인 뒤 숨으면 조사 상태로 들어가는가?
- 추격 중 벽 뒤로 숨으면 마지막 목격 위치까지 오는가?
- 수색이 끝난 뒤 다시 순찰하는가?
- 경비가 벽을 뚫거나 모서리에 계속 걸리지 않는가?
- 경계 레벨이 높을수록 실제로 더 위협적인가?
