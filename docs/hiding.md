# 숨기 시스템

이 문서는 은신처 진입과 이탈, 경비의 은신처 조사, 체포 규칙을 설명한다.

## 개발 목표

숨기는 무조건 안전한 버튼이 아니다. 경비가 보지 않을 때 적절한 위치에서 사용하면 위험을 넘길 수 있지만, 숨는 모습을 들키거나 가까이서 소리를 내면 은신처가 조사 대상이 된다.

## 은신처

현재 맵에는 4개의 은신처가 있다.

| 은신처 | 종류 |
|---|---|
| 서관 벽면 커튼 | 외벽에 붙은 작업용 커튼 |
| 조각 전시대 뒤 | 조각 회랑 안 전시대의 남쪽 사각지대 |
| 직원용 보관함 | 중앙 벽면에 붙은 3칸 보관함 |
| 기록 선반 사이 | 기록실 벽에 붙은 높은 서류 선반 |

종류에 따라 그림은 다르지만 현재 게임 규칙은 모두 같다.

은신처는 길 한복판의 원형 바닥 표식으로 사용하지 않는다. 커튼과 보관함은 벽에 붙이고, 전시대와 기록 선반은 주변 박물관 설비와 이어지도록 배치한다. 각 은신처에는 실제 가로·세로 크기와 접근 방향이 있다.

조각 전시대는 좁은 남쪽 통행로에서 제거하고 맵 왼쪽 위의 조각 회랑 안으로 옮겼다. 플레이어는 전시대 남쪽에서 접근해 숨으므로, 이동을 막는 임의의 상자가 아니라 전시 공간을 활용하는 은신처로 보인다.

동관 보수 커튼은 주변 공간과 역할이 자연스럽게 연결되지 않아 제거했다. 단순히 은신처 수를 맞추기 위해 다른 통로로 옮기지는 않는다.

- 캐릭터와 경비원은 은신 설비를 통과할 수 없다.
- 입구 쪽에 접근해야 E 안내가 나타난다.
- 나올 때도 먼저 입구 쪽의 안전한 위치를 사용한다.
- 경비원이 확인할 때는 설비 중심이 아니라 실제 입구 앞으로 이동한다.

## 진입과 이탈

- 은신처 가까이에서 E를 누르면 숨는다.
- 숨어 있는 동안 이동할 수 없다.
- 다시 E를 누르면 은신처에서 나온다.
- 보물을 가진 상태에서도 숨을 수 있다.
- 숨어 있는 동안 플레이어 캐릭터는 화면에서 사라진다.
- 카메라는 은신처 중심으로 전환되고 외부는 설비의 좁은 틈으로만 볼 수 있다.
- 경비 발소리는 계속 들린다.

## 숨는 장면을 목격한 경우

경비 시야 안에서 숨으면 경비가 해당 은신처를 기억한다.

```text
플레이어가 숨음
→ 경비가 은신처를 목격
→ HIDE_CHECK 상태
→ 은신처 앞으로 이동
→ 약 1초 동안 문고리·문을 확인
→ 내부 확인
→ 플레이어가 아직 안에 있으면 체포
```

목격된 은신처는 붉은색으로 표시되고 틈 테두리와 화면 아래 문구가 `HOLD STILL`로 바뀐다. 경비가 문을 여는 데 약 1초가 걸리므로, 플레이어는 위험을 감수하고 먼저 나올 마지막 기회를 가진다.

## 목격하지 못한 경우

경비가 숨는 장면을 보지 못하면 플레이어를 바로 잡을 수 없다. 하지만 다음 상황에서는 조사할 수 있다.

- 경비가 가까운 거리에서 진입 소리를 들음
- 경비가 가까운 거리에서 이탈 소리를 들음
- Level 2 이상에서 마지막 목격 위치 가까이에 은신처가 있음

높은 경계 단계의 주변 은신처 확인에는 확률이 적용된다. 따라서 같은 은신처가 항상 안전하다고 보장할 수 없다.

## 은신처에서 나오기

- 경비가 출구 방향을 보고 있으면 나오는 순간 추격이 시작될 수 있다.
- 경비가 시야 밖이더라도 가까우면 이탈 소리를 듣고 조사한다.
- 경비가 목격한 은신처를 확인하러 오는 동안 먼저 나와 도망칠 수 있다.

## 경비 상태 연동

은신처 확인에는 `HIDE_CHECK` 상태를 사용한다. 경비가 빈 은신처를 확인하면 마지막 위치 주변을 수색한다.

전체 경비 상태 흐름은 [경비원 AI](guard-ai.md)에서 관리한다.

## 화면과 사운드

- 보관함은 폭을 넓힌 세 개의 세로 문틈으로 외부를 본다.
- 기록 선반은 가는 선이 아니라 박스 사이에 생긴 크고 작은 세 개의 불규칙한 틈을 사용한다.
- 커튼은 불규칙한 중앙 이음새, 전시대 뒤는 바닥에 가까운 넓은 가로 틈을 사용한다.
- 틀 밖은 완전한 검정이 아니라 매우 어두운 청회색으로 남고, 금속 기둥·선반·상자·라벨·먼지가 희미하게 보인다.
- 경비와 손전등은 틈을 지나가는 부분만 보이므로 정확한 전체 위치는 알 수 없다.
- 가장 가까운 경비의 방향은 화면 상하좌우의 청각 파동 위치로 표현한다.
- 가까워질수록 파동의 크기, 밝기, 개수와 퍼지는 속도가 증가한다.
- 경비가 가까워질수록 화면 가장자리의 청각 파동, 붉은 압박 효과와 심장 박동이 강해진다.
- 가까운 경비의 그림자는 틈 안에서 더 커지고, 경비가 은신처를 바라보면 손전등 빛이 틈으로 들어온다.
- 경비가 은신처를 확인하면 틈과 문짝이 흔들린다.
- 진입, 이탈, 은신처 확인에 서로 다른 효과음을 사용한다.

정확한 경비 좌표를 공개하지 않는 이유는 숨은 상태에서도 발소리와 짧게 보이는 실루엣을 조합해 판단하게 하기 위해서다.

상세 표현은 [UI와 그래픽](ui-and-visuals.md), 소리 규칙은 [사운드](audio.md)에서 관리한다.

## 직접 확인할 것

- 경비가 보지 않을 때 숨으면 지나쳐 가는가?
- 숨는 장면을 목격하면 은신처까지 찾아오는가?
- 경비가 도착하기 전에 나오면 도망칠 기회가 있는가?
- 높은 경계 단계에서 주변 은신처를 확인할 수 있는가?
- 은신 중에도 발소리 방향을 추측할 수 있는가?
- 경비가 틈 앞을 지나갈 때 몸과 손전등의 일부만 보여 긴장되는가?
- 선반 내부가 UI 선이 아니라 실제 금속 프레임과 박스 구조로 느껴지는가?
- 가까워질수록 청각 파동과 심장 박동이 자연스럽게 강해지는가?
- 은신처 확인 전에 문 흔들림과 대응 시간이 보이는가?
- 숨기가 무조건 안전한 해결책이 되지 않는가?
- 은신처가 통로 한가운데 놓인 게임 표식이 아니라 실제 박물관 설비처럼 보이는가?
- 캐릭터와 경비원이 은신 설비 위를 통과하지 않는가?
