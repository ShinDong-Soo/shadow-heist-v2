# 문과 출입 권한

이 문서는 일반 문, 잠금문, 키카드와 문 조작 소음의 규칙을 설명한다.

## 문 종류

| 문 | 시작 상태 | 잠금 | 역할 |
|---|---|---|---|
| 서쪽 전시실 문 | 닫힘 | 없음 | 안전한 우회와 빠른 진입 중 선택하게 한다. |
| 중앙 통로 문 | 열림 | 없음 | 문을 닫아 시야와 이동 경로를 바꿀 수 있다. |
| 왕관 보관실 보안문 | 닫힘 | 키카드 | 가장 비싼 보물에 바로 접근하지 못하게 한다. |

문 가까이에서 E를 누르면 열린 문은 닫히고 닫힌 문은 열린다.

## 충돌과 시야

- 닫힌 문은 벽처럼 플레이어와 경비의 이동을 막는다.
- 닫힌 문은 경비, CCTV, 플레이어 시야와 조명을 가린다.
- 열린 문은 충돌과 시야 계산에서 제외된다.
- 문이 바뀌면 경비가 새 길을 계산하고 조명 범위도 다시 계산한다.
- 플레이어나 경비가 문틀 안에 있으면 문을 닫을 수 없다.

쉽게 말하면 닫힌 문은 `움직일 수 있는 벽`이다. 공통 시야 계산은 [맵, 시야, 조명](map-vision-lighting.md#시야-계산-방식)에서 설명한다.

## 키카드와 보안 구역

왕관 보관실은 벽과 잠긴 보안문으로 둘러싸여 있다.

1. 기록 보관 구역에서 `보안 키카드`를 찾는다.
2. 가까이에서 E를 눌러 획득한다.
3. HUD의 `ACCESS`가 `키카드`로 바뀐다.
4. 왕관 보관실 보안문으로 이동해 E를 누른다.

키카드 없이 보안문을 사용하면 잠금음만 나고 문은 열리지 않는다. 키카드는 한 번 획득하면 해당 플레이가 끝날 때까지 유지된다.

## 문 조작 소음

- 문 열기 소음 범위: 255
- 문 닫기 소음 범위: 315
- 벽이 사이에 있으면 실제 청취 거리가 감소한다.
- 경계 단계가 높을수록 경비의 청취 거리가 증가한다.
- 경비가 들으면 문 위치를 조사한다.
- 잠긴 문을 건드리는 작은 소리는 경비 조사까지 유발하지 않는다.

문을 닫는 행동이 더 큰 소리를 내므로 시야를 차단하는 이점과 경비를 부를 위험이 함께 생긴다. 소리 전달 계산은 [사운드](audio.md#플레이어-발소리와-소음)와 같은 규칙을 사용한다.

## 직접 확인할 것

- 닫힌 문을 플레이어와 경비가 통과하지 못하는가?
- 열린 문 너머로 시야와 조명이 이어지는가?
- 문을 닫으면 경비와 CCTV의 시야가 차단되는가?
- 키카드 없이 왕관 보관실에 들어갈 수 없는가?
- 키카드를 얻은 뒤 보안문이 열리는가?
- 경비가 가까울 때 문을 여닫으면 문 위치를 조사하는가?
- 플레이어나 경비가 문틀 안에 있을 때 문이 닫히지 않는가?
- 재시작하면 문과 키카드가 초기 상태로 돌아가는가?
