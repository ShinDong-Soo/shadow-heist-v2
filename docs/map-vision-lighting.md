# 맵, 시야, 조명

이 문서는 박물관 구조, 벽 충돌, 제한 시야, 광원과 노출도 규칙을 설명한다.

문은 상태에 따라 충돌과 LOS가 달라지는 동적 장애물이다. 문 배치와 조작 규칙은 [문과 출입 권한](doors-and-access.md)에서 관리한다.

## 박물관 맵

- 전체 게임 공간은 하나의 고정된 맵이다.
- 외벽, 내부 벽, 전시대, 기둥이 배치되어 있다.
- 서관, 조각 회랑, 중앙 전시실, 보존실, 왕관실, 기록 보관소로 구역을 구분한다.
- 플레이어 위치를 따라 카메라가 부드럽게 이동한다.
- 랜덤 맵은 아직 사용하지 않는다.

충돌 계산은 캐릭터를 원으로, 벽과 전시대를 직사각형으로 처리한다.

## 플레이어 제한 시야

- 플레이어 주변의 제한된 범위만 정상적으로 보인다.
- 벽과 전시대 뒤쪽은 볼 수 없다.
- 시야 밖의 맵, 보물, 경비원은 어둠에 가려진다.
- 시야 경계는 단순한 원이 아니라 실제 벽 모양에 맞춰 잘린다.

### 시야 계산 방식

플레이어 주변으로 여러 개의 가상 선을 쏜다. 선이 벽을 만나면 그 위치에서 멈춘다. 이렇게 얻은 점을 이어 현재 보이는 영역을 만든다.

어둠은 별도의 임시 Canvas에 먼저 그린 뒤 게임 화면에 합성한다. 이 방식은 시야를 밝히는 과정에서 맵과 캐릭터까지 함께 지워지는 문제를 방지한다.

## 탐색 기억

한 번 직접 본 구역은 현재 시야 밖으로 나가도 완전히 처음 상태로 돌아가지 않는다.

- 아직 방문하지 않은 구역은 가장 짙은 어둠으로 표시한다.
- 한 번 본 구역은 조금 옅은 청회색 어둠으로 표시한다.
- 현재 보고 있는 구역만 정상 밝기로 표시한다.
- 기억 영역은 현재 플레이 중에만 유지되고 재시작하면 초기화된다.
- 닫힌 문 너머처럼 LOS가 막힌 구역은 직접 보기 전까지 탐색되지 않는다.
- 문을 열어 확인한 뒤 다시 닫아도 이미 본 구역의 기억은 남는다.

탐색 기억은 길을 되짚는 데만 도움을 준다. 시야 밖 경비, 보물, CCTV의 현재 상태는 여전히 짙은 안개 아래에 가려지므로 실시간 위치 정보로 사용할 수 없다.

### 탐색률 계산

박물관의 이동 가능한 공간을 약 60픽셀 크기의 칸으로 나눈다. 일정 간격마다 다음 조건을 만족하는 칸을 탐색 완료로 기록한다.

1. 현재 플레이어 시야 거리 안에 있다.
2. 플레이어와 칸 중심 사이를 벽이나 닫힌 문이 막지 않는다.

탐색한 칸 수를 전체 이동 가능한 칸 수로 나눈 값이 HUD의 `MAP` 탐색률이다.

## 광원

현재 사용하는 광원은 다음과 같다.

- 세 보물의 전시 스포트라이트
- 서관, 중앙, 동관의 복도 조명
- 일부 점멸 형광등
- 경계 단계별 붉은 비상등

빛도 플레이어 시야와 같은 방식으로 벽에서 차단된다. 광원과 가까울수록 강하며, 플레이어와 광원 사이에 벽이 있으면 해당 빛은 플레이어에게 닿지 않는다.

## 플레이어 노출도

활성 광원의 거리, 세기, 벽 차폐를 합산해 현재 노출도를 계산한다.

```text
어두움 → 희미함 → 노출됨 → 매우 밝음
```

- 밝은 곳에서는 플레이어가 볼 수 있는 범위가 넓어진다.
- 밝은 곳에서는 경비원의 탐지 거리와 감지 속도가 증가한다.
- 어두운 곳에서는 시야가 좁어지지만 경비에게 덜 보인다.

경비가 노출도를 사용하는 방법은 [경비원 AI](guard-ai.md#밝기와-탐지)에서 설명한다.

## 보물 및 경계 단계 연동

- 보물을 훔치면 해당 전시 스포트라이트가 꺼진다.
- CCTV 경보로 경계가 올라가도 비상등이 활성화된다.
- 경계 Level 1에서 서쪽 비상등이 켜진다.
- 경계 Level 2에서 중앙 비상등이 추가된다.
- 경계 Level 3에서 동쪽 비상등까지 켜진다.

경계 단계의 전체 규칙은 [강탈과 점수](heist-and-scoring.md#전역-경계-단계)에서 관리한다.

## 조명 스위치

- 서관, 중앙, 동관에 한 개씩 배치되어 있다.
- E를 누르면 해당 구역 조명을 켜거나 끈다.
- 각 스위치는 한 판에 한 번만 사용할 수 있다.
- 조작 시 경비가 스위치 위치를 조사한다.

## 렌더링 성능

벽에 잘린 광원 모양은 처음 한 번 계산한 뒤 저장해서 재사용한다. 광원과 벽은 움직이지 않으므로 매 화면마다 같은 계산을 반복할 필요가 없다.

## 직접 확인할 것

- 모든 보물과 출구로 이동할 수 있는가?
- 벽 뒤의 경비원과 보물이 보이지 않는가?
- 밝은 장소에서 시야와 `EXPOSURE`가 증가하는가?
- 같은 거리에서도 밝은 장소에서 더 빠르게 발각되는가?
- 스위치와 보물 획득이 실제 조명 상태를 바꾸는가?
- 한 번 본 구역이 시야 밖에서 희미한 기억으로 남는가?
- 탐색 기억 때문에 시야 밖 경비가 쉽게 보이지는 않는가?
- 재시작하면 탐색률과 기억 영역이 초기화되는가?
